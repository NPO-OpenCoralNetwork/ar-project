| フェーズ | 目的 | 主な成果物 | 次へ進む条件 |

## 1. 決定事項（2026-10-16）

| 項目 | 決定内容 |
|---|---|

## 2. 目的と成功の定義

**目的:** 妖怪たちとの関係を通して、プレイヤーが「立山という土地の物語」を自分ごととして知ること。その結果、現地に行きたくなり、行ったときには長く深く歩き回るようになること。

**MVP で確かめる仮説**

| # | 仮説 |
|---|---|
| H1 コアループ | 「歩く→出会う→話す→悩みを解く→伝承が開く」の流れが、作業ではなくゲームとして面白い |
| H2 学び | 遊んだ人が伝承を楽しく覚えていて、翌日、人に話せる |
| H3 会話 | LLM で妖怪と話せることが、固定の台本だけの場合よりキャラクターへの愛着を深める |
| H4 現地性 | 実際にその場所へ行くことに価値を感じる（家でできる部分との差がはっきりしている） |

**成功指標（プレイテスト10〜20人、目標値は仮）**

| 指標 | 目標 |
|---|---|
| テスト後に「また遊びたい」と答えた人の割合 | 70% 以上 |
| 翌日、教わった伝承を1つ以上、自分の言葉で説明できた人の割合 | 60% 以上 |
| 1回のプレイ時間 | 20〜40分 |
| 安全面のヒヤリハット | 0件 |
| 妖怪が伝承と違うことを言った件数（監修チェックで判定） | 0件 |

## 3. ターゲットとペルソナ

| | A: 旅する和もの好き | B: 地元を再発見する人 |
|---|---|---|
| 人物像 | 30代・東京在住・会社員。御朱印帳は3冊目。北陸新幹線で約2時間かけて富山へ来る | 40代・富山市在住。週末に散歩や家族で外出する |
| 動機 | 旅先で、その土地ならではの物語に触れたい。ガイドブックをなぞるだけでは物足りない | 立山は毎日見ているのに、立山信仰のことはほとんど知らない |
| 遊び方 | 旅行中の1〜2日に集中して深く遊ぶ。帰宅後は「おうちモード」で妖怪と話し続ける | 普段の散歩で少しずつ遊ぶ。季節イベントのたびに戻ってくる |

- 観光客は一度きりの来訪になりやすい。そこで、**帰ったあとも仲良くなった妖怪と話せる**ことを、再訪の動機にする（F-25）。
- MVP のテストは18歳以上に限る。一般公開時の年齢の方針は別途決める。

## 4. MVP の範囲

### 4.1 舞台は「里・麓・山」の三層（提案）

かつての立山参詣（立山禅定）は、平野の里から麓の宗教村（岩峅寺・芦峅寺）を経て、山（室堂・雄山）へ登る道のりだった。**ゲームの進み方を、この巡礼の道のりに重ねる。**

| 層 | 場所（候補） | 特徴 | MVP での扱い |
|---|---|---|---|
| 里 | 富山市街（富山駅周辺など） | 交通の起点。一年中行けて、観光客が必ず通る | 導入部分と、普段の散歩で会える妖怪 |
| **麓** | 立山町の岩峅寺・芦峅寺（雄山神社の前立社壇・中宮祈願殿、立山博物館） | 立山信仰の中心地。一年中行ける（冬は雪） | **MVP のメイン舞台。** 主ストーリー1本 |
| 山 | 室堂平・雄山 | 雷鳥、地獄谷、山頂の峰本社。行けるのはアルペンルートの営業期間だけ（2026年度は4/15〜11/30） | MVP では予告だけ。季節限定のクライマックスとして後で作る |

> 山の層を MVP から外す理由:
> - 半年近く行けない
> - 電波が届かない区間がある（美女平〜天狗平間など）
> - 地獄谷の歩道は火山ガスのため2012年度から通行止め
> - ライチョウ保護区域は立入禁止
>
> 安全とオフライン対応が整ってから扱う。

### 4.2 「現代の立山曼荼羅」（収集画面の考え方）

江戸時代、芦峅寺や岩峅寺の宗徒は、立山曼荼羅を見せながら絵の内容を語って聞かせ（絵解き）、立山の地獄と浄土を各地に伝えた。
このゲームの収集画面は**「自分だけの立山曼荼羅」**にする。妖怪と縁を結んだり伝承を知ったりするたびに、曼荼羅の一部が描き込まれていく。

### 4.3 コンテンツの量（MVP）

| 種類 | 量 |
|---|---|
| 妖怪・神の使いなどのキャラクター | 10〜15体（麓8〜10、里3〜5） |
| 主ストーリー | 1本（例: 立山開山の物語をたどる） |
| 悩みごと（クエスト） | 15〜20個 |
| 曼荼羅のピース（伝承の断片） | 20〜30 |
| 供物（名産品） | 5〜8種 |

## 5. 機能要件

優先度: **Must**＝MVP に必須 ／ **Should**＝できれば入れる ／ **Could**＝余裕があれば ／ **Won't**＝MVP ではやらない

### 5.1 探索（地図・位置）
| ID | 機能 | 内容 | 優先度 |
|---|---|---|---|
| F-01 | 現在地と和風地図 | 現在地を中心に、和風の絵柄で描いた地図を出す | Must |
| F-02 | 気配 | 近く（目安100〜300m）にいる妖怪の気配を、地図上の揺らぎで示す | Must |
| F-03 | 出現ルール | 場所の種類（社寺・川・森・橋など）と時間帯（昼・逢魔が時・夜）で出る妖怪が変わる。季節による変化は Should | Must |
| F-04 | 固定配置 | 主ストーリーの妖怪は、伝承地に固定して置く | Must |
| F-05 | 安全な配置 | 妖怪を置くのは公道と公開されている場所だけ。立入禁止・私有地・危険な場所は除外リストで管理する | Must |
| F-06 | 位置シミュレーター（開発用） | 地図上のどこにでも「いるふり」ができる。立山には頻繁に行けないので必須 | Must |
| F-07 | テスト用コンテンツ | チームの地元の地点にテスト用の妖怪を割り当て、仕組みの検証を地元で回せるようにする | Must |
| F-08 | オフライン | 電波がない場所でも、先にダウンロードしたエリアの地図・妖怪・固定会話で遊べる。山の層を作る時点で Must にする | Should |

### 5.2 出会い・表示
| ID | 機能 | 内容 | 優先度 |
|---|---|---|---|
| F-10 | カメラなし表示 | 和風の背景の上に妖怪が現れる（段階0。PC でも動く） | Must |
| F-11 | カメラ AR | カメラ映像に妖怪を重ね、スマホの傾きに追従させる（段階1） | Must |
| F-12 | 記念写真 | 妖怪との写真を保存・共有できる | Should |
| F-13 | 地面に立つ AR | 段階2。MVP では技術検証だけ行う | Won't |

### 5.3 会話
| ID | 機能 | 内容 | 優先度 |
|---|---|---|---|
| F-20 | 台本の会話 | 主ストーリーと伝承の事実は、人が書いて監修した台本で進める | Must |
| F-21 | LLM の雑談 | 妖怪の性格・口調で短い雑談ができる。その妖怪が「知っていてよい」伝承テキストだけを参照する | Must（H3 を確かめるため） |
| F-22 | 会話の安全策 | 伝承の作り話を禁止し、話題がそれすぎないよう制限し、不適切な入力を弾く。費用を管理するため1日の会話回数に上限を設ける | Must |
| F-23 | 入力方法 | 選択肢と自由入力（文字）。音声入力は Could | Must |
| F-24 | 縁（関係値） | 会話・贈り物・悩みの解決で縁が深まり、話す内容が変わっていく | Must |
| F-25 | おうちモード | 現地を離れても、縁を結んだ妖怪と話したり曼荼羅を眺めたりできる。新しい出会いは現地でしか起きない。PC ではこれが主な遊び方になる | Should（H4 を確かめるため） |

### 5.4 悩みごと（クエスト）
| ID | 機能 | 内容 | 優先度 |
|---|---|---|---|
| F-30 | 悩みの3つの型 | 調べる（場所を訪ねて手がかりを見つける）／届ける（供物や伝言を運ぶ）／とりもつ（妖怪同士の仲を直す） | Must |
| F-31 | 鎮め（ミニゲーム） | 荒ぶる妖怪を和の遊びで鎮める。MVP では1種類だけ作り、入れるかどうかを試作で判断する | Should |
| F-32 | 主ストーリー | 里から麓へとたどる物語を1本 | Must |

### 5.5 収集・記録
| ID | 機能 | 内容 | 優先度 |
|---|---|---|---|
| F-40 | 妖怪帳 | 縁を結んだ妖怪と、出典付きの解説 | Must |
| F-41 | 立山曼荼羅 | 伝承を知るたびに描き込まれていく収集画面 | Must |
| F-42 | 供物（名産品） | 妖怪の好物として出てくるアイテム | Should |
| F-43 | 出典の表示 | 伝承のテキストには、出典（文献・監修者）を必ず添える | Must |

### 5.6 アカウント・データ
| ID | 機能 | 内容 | 優先度 |
|---|---|---|---|
| F-50 | 登録なしで開始 | 端末内に保存して、すぐ遊べる | Must |
| F-51 | 引き継ぎ | 端末を替えてもデータを引き継げる | Should |
| F-52 | 位置情報の最小化 | 位置情報はゲームの進行に必要な範囲だけで使い、移動の履歴はサーバーに保存しない | Must |

### 5.7 安全
| ID | 機能 | 内容 | 優先度 |
|---|---|---|---|
| F-60 | 最初の注意 | 歩きスマホ、立入禁止、自然保護についての注意を表示する | Must |
| F-61 | 移動中の制限 | 歩くより速く動いているとき（車・電車）は、会話など画面を注視する操作を制限する | Must |
| F-62 | 夜の扱い | 夜に出る妖怪は「気配が分かる」程度にとどめ、夜の外出を促さない | Must |
| F-63 | 自然保護 | 「実在のライチョウには近づかない・追わない」と、ゲーム内の雷鳥自身に語らせる | Should |

### 5.8 運営・地域連携
| ID | 機能 | 内容 | 優先度 |
|---|---|---|---|
| F-70 | データで管理 | 妖怪・スポット・伝承・台本を JSON やスプレッドシートで管理し、コードを触らずに追加・修正できるようにする | Must |
| F-71 | 監修の状態 | 各コンテンツに「下書き／監修中／監修済み」を持たせ、監修済みのものだけを公開する | Must |
| F-72 | 協力先の枠 | 協力してくれる店舗や施設を「供物がもらえる場所」などとして登録できる。MVP では項目だけ用意する | Could |
| F-73 | 協力先への集計 | スポットごとの訪問数を、個人が分からない形で集計する | Could |

### 5.9 MVP ではやらないこと（Won't）
- マルチプレイ、フレンド、交換
- 課金、広告
- AR グラス対応
- 段階2・3の AR（技術検証だけ行う）
- バックグラウンドでの位置記録、プッシュ通知
- 英語などの多言語対応（ただし、文言は後で翻訳できる形で管理しておく）
- アプリストアでの配信（まずは Web で検証）
- 山（室堂・雄山）の層（予告だけ）

## 6. 非機能要件

| 区分 | 要件 |
|---|---|
| 対応環境 | iPhone: iOS 26 以降の Safari ／ Android: 発売から3年以内の中位機種以上の Chrome ／ PC: 最新の Chrome・Safari・Edge（PC は主に「おうちモード」） |
| 動作の軽さ | 中位機種で 30fps 以上。最初の読み込みは 10MB 以内が目安（地図や画像は必要になった分だけ読み込む） |
| 電池 | 地図画面で30分遊んで、電池の消費が10%以内（AR 表示中は除く） |
| 通信 | 4G で快適に動く。電波が弱いときは台本の会話に切り替えて、遊び続けられるようにする |
| 会話の速さ | LLM が返事を出し始めるまで2秒以内 |
| 費用 | LLM の費用に、1人1日あたりの上限と、MVP 期間全体の上限を設ける（金額は別途決める） |
| プライバシー | 位置情報の扱いを利用規約とプライバシーポリシーに明記する。個人情報保護法に従う |
| 読みやすさ | 文字の大きさを変えられる。読みにくい地名や神仏の名前にはふりがなを振る。色だけで情報を伝えない |
| 正確さ | 伝承についての記述は、すべて出典付きで監修を通す。LLM には伝承の新しい「事実」を作らせない |

## 7. コンテンツ要件

### 7.1 妖怪データの項目（案）

| 項目 | 説明 | 例（雷鳥） |
|---|---|---|
| 名前・読み | 表示名とふりがな | 雷鳥（らいちょう） |
| 種別 | 妖怪／神の使い／神仏ゆかり／土地の主 など | 神の使い |
| 出典 | 文献・資料、監修者 | 03 のリサーチ結果を参照 |
| ゆかりの場所 | 座標と半径、層（里・麓・山） | 室堂平（山）。麓では「噂」として登場 |
| 出現条件 | 場所の種類・時間帯・季節・ストーリーの進み具合 | 主ストーリーが一定まで進んだあと |
| 性格・口調 | LLM に渡すキャラクター設定 | 誇り高く、少し気難しい |
| 悩みごと | クエストの種 | （GDD で設計） |
| 好物（供物） | 名産品との接点 | （GDD で設計） |
| 関係 | 他の妖怪や神仏とのつながり | 立山の神とのつながり（03 で検証） |
| 知っていてよい伝承 | LLM が参照してよいテキストの範囲 | 監修済みのテキストだけ |
| 開く曼荼羅のピース | 縁が深まると描き込まれる部分 | — |
| 監修の状態 | 下書き／監修中／監修済み | 下書き |
| 注意事項 | 宗教的な配慮や自然保護など | 実在のライチョウは特別天然記念物 |

### 7.2 監修の流れ
下書き（チーム、AI が補助）→ 出典の確認 → 監修者によるレビュー → 公開

### 7.3 宗教・文化への配慮（ルール案）
- **神仏そのものはキャラクターにしない。** 神仏は「姿を見せない存在」として扱い、雷鳥のような神の使いや妖怪を通して語る。
- 社寺の名前や由緒を載せる前に、了承を得る。
- 境内では参拝者の邪魔にならないよう、撮影のルールなども案内する。
- 立山地獄など、死や地獄にまつわる伝承は「畏れ」の演出には使うが、茶化さない。
