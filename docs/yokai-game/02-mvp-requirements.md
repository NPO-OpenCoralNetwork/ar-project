## 2. 目的と成功の定義

**目的:** 妖怪たちとの関係を通して、プレイヤーが「立山という土地の物語」を自分ごととして知ること。その結果、現地に行きたくなり、行ったときには長く深く歩き回るようになること。

**MVP で確かめる仮説**

| # | 仮説 | いつ確かめるか |
|---|---|---|
| H1 コアループ | 「歩く→出会う→話す→悩みを解く→伝承が開く」の流れが、作業ではなくゲームとして面白い | 段階2（一部）、段階3のテスト、1月のおうちテスト、3月の現地テスト |
| H2 学び | 遊んだ人が伝承を楽しく覚えていて、翌日、人に話せる | 1月のおうちテスト、3月の現地テスト |
| H3 会話 | LLM で妖怪と話せることが、固定の台本だけの場合よりキャラクターへの愛着を深める | **3月のテストの後**（段階6）。3月のテストは台本だけで行う |
| H4 現地性 | 実際にその場所へ行くことに価値を感じる（家でできる部分との差がはっきりしている） | 3月の現地テスト。確かめ方は 04 §6.3 のまま（別々の札を家と現地で知ってもらい、順番を入れ替える）。聞き取りに「家で会った妖怪に現地で再会して、嬉しかったか、作業に感じたか」を足す |

**成功指標（3月の現地テスト10〜20人、目標値は仮）**

|---|---|
| テスト後に「また遊びたい」と答えた人の割合 | 70% 以上 |

| | A: 旅する和もの好き | B: 地元を再発見する人 |
|---|---|---|

## 4. MVP の範囲

### 4.1 舞台は「里・麓・山」の三層

かつての立山参詣（立山禅定）は、平野の里から麓の宗教村（岩峅寺・芦峅寺）を経て、山（室堂・雄山）へ登る道のりでした。**ゲームの進み方を、この巡礼の道のりに重ねます。**（10/17 決定）
> この段落は**設計の前提**で、伝承の事実ではありません。「立山禅定」「宗教村」は 03 に出典の行がないので、03 に出典つきの行を足すまで、札・台本には使いません（伝承の事実は 03 の内容だけ）。

| 層 | 場所（候補） | 特徴 | MVP での扱い |
|---|---|---|---|
| 里 | 富山市街（富山駅周辺など） | 交通の起点。一年中行けて、観光客が必ず通る | 序章と、普段の散歩で会える妖怪（一部） |
| **麓** | 立山町の岩峅寺・芦峅寺（立山博物館の周りを含む） | 立山信仰の中心地。一年中行ける（冬は雪） | **MVP のメイン舞台。** 主ストーリー1本。夢の旅の3Dの箱庭も、まず岩峅寺に1か所作る |
| 山 | 室堂平・雄山 | 雷鳥、地獄谷。行けるのはアルペンルートの営業期間だけ（2026年度は4/15〜11/30） | MVP では予告だけ。季節限定のクライマックスとして後で作る |

> 山の層を MVP から外す理由:
> - 半年近く行けない
> - 電波が届かない区間がある（美女平〜天狗平間など）
> - 地獄谷の歩道は火山ガスのため2012年度から通行止め
> - ライチョウ保護区域は立入禁止
>
> 安全とオフライン対応が整ってから扱います。

**夢の旅の箱庭の範囲（05 §4.1）**
- 箱庭は「街全体の複製」にしません。数百m四方の小さな場所にし、妖怪の悩みをほどくための舞台にとどめます。
- **作るのは境内の外の公道と広場だけ**です。境内は「お休みの範囲」として霧にし、中には入れません。社殿・鳥居・宿坊・個人の家は作り込まず、名前のない一般的な家並みにします。
- 社寺名・由緒は、了承を得るまで画面にもデータにも出しません。地点の札は「この地点」と書きます（04 §5.2）。
- 布橋のまわりは、関係者の了承と第三章の判断（2月初め）が出るまで箱庭に入れません。
- 岩峅寺の箱庭の具体の範囲と作り方は §5.10（F-26）に書きます。

### 4.2 「現代の立山曼荼羅」（収集画面の考え方）

江戸時代、芦峅寺の衆徒は立山曼荼羅を携えて全国の檀那場を廻りました。曼荼羅を見せながら絵の内容を語って聞かせ（絵解き）、護符や反魂丹を配って、立山の地獄と浄土を各地に伝えました（[03](03-tateyama-folklore-research.md) #4・#20）。

- このゲームの収集画面は**「自分だけの立山曼荼羅」**にします。妖怪と縁を結んだり伝承を知ったりするたびに、曼荼羅の一部が描き込まれていきます。夢の旅では白描（線）まで、現地に立つと色が入ります。
- プレイヤーの役割は**「現代の絵解き師（見習い）」**です。集めた物語を人に語る（共有する）ことが、そのままゲームの目的になり、仮説 H2（人に話せる）とも直結します。
- 曼荼羅帳は「旅の一冊」も兼ね、巻末に旅印（仮）を押します（§4.5）。新しい帳面は増やしません。

### 4.4 二つの旅の線引き（05 §3。最初に公開して、後から削らない）

| | 夢の旅（家・PC／スマホ） | 現の旅（現地・スマホ） |
|---|---|---|
| 入り方 | 地域を選ぶ → その土地の3Dの箱庭に入る | 現地で GPS の地図を開く |
| 動き方 | アバター（絵解き師の見習い）と相棒のましろで歩く。名所で「指を置いて耳を澄ます」と、数秒で妖怪の姿が浮かぶ | 自分の足で歩く。立ち止まると妖怪が現れる |
| 妖怪の姿 | 白描（墨の線だけ）の「夢の姿」 | 色のついた本当の姿 |
| 会話 | 台本。段階6から、「なじみ」以上の妖怪と端末内 LLM の雑談 | 台本（段階6から LLM の雑談）。本人がその場所でだけ話す台詞がある |
| 悩みごと・鎮め | 家でも始めて、解ける | 現地でも始めて、解ける |
| 物語 | **最後まで進められる**。打ち明け話は、古笠の便りやましろの「また聞き」として読める | 同じ打ち明け話を、妖怪本人がゆかりの地点で語る |
| 縁 | 「顔見知り」→「なじみ」まで | 「語り仲間」「えにし」まで上がる |
| 曼荼羅 | 白描（線）まで | 色が入る。家で語り返すと金の縁取り |
| 行った証 | 枠だけ見える | 日付入りの「旅印（仮）」 |

**ルール**
1. 家の遊びを不利にして現地へ行かせるのではなく、現地で上乗せします。
2. 物語の本編は、現地に行かなくても最後まで遊べます（遠くに住む人、行けない事情のある人のため）。
3. 現地でしか手に入らないのは「色・語り仲間とえにし・旅印・その場でしか聞けない台詞」です。
4. 一度配ったものは、後から取り上げません。家でできることは、控えめに始めて広げる方向にだけ動かします。

**再会**: 家で先に会った妖怪は、現地で【創作】「夢で見た顔だな……本当に来たのか」と迎えます。家で遊んだことが、現地の驚きを減らすのではなく増やすように作ります。

### 4.5 行った証（旅印・仮）のルール（05 §3.2）

| 決まり | 理由 |
|---|---|
| 「御朱印」「お守り」と呼ばない。見た目も似せない（朱の印と墨書きの組み合わせ、お札・袋・紐の形を使わない） | 御朱印は「参拝した証」とされ、授与品の転売を戒める社寺もある |
| 旅印（仮）は、駅スタンプのようなインク1色の絵柄スタンプにして、曼荼羅帳の巻末に押す。日付が入る | 宗教と関係のない「印を集める」文化に寄せる |
| お金では売らない。人に譲れないようにする。交換・ランキングも作らない | 転売・行列・競争を防ぐ |
| 本物の御朱印・お守りは、ゲームの外の正式なものとして扱い、ゲームの進行やご褒美とは結びつけない。案内は雄山神社の了承を得てから、公式の案内へのリンクと参拝マナーだけにする | 社寺の考えは未確認 |
| **MVP（3月のテストまで）は GPS だけで確かめる**。偽装は許容する。協力先に置く NFC タグは、テストの後で検討する | Web の位置情報は簡単に偽装できるが、MVP では守る価値と手間が釣り合わない |
| 妖怪からの品は「まもり」と呼ばず、供物・贈り物の枠（04 §3.7）で扱う | 「お守り」と同じ音で、効き目をにおわせるため |

### 7.2 監修の流れ
下書き（チーム、AI が補助）→ 出典の確認 → 監修者によるレビュー → 公開。1月からは、章ごとに監修へ送ります（05 §6 段階5）。

### 7.3 宗教・文化への配慮（ルール）
- **今も信仰の対象として祀られている神仏は、キャラクターにしません。** 立山権現・刀尾権現・阿弥陀如来・不動明王・姥尊（おんばさま）などは姿を描かず、妖怪は「あのお方」「山の神さま」と呼びます。語りは、雷鳥（「立山の神さまの使い」として台本だけ）や、光蔵坊などの妖怪を通して行います。開山の白鷹には話させず、ましろも白鷹としては話させません（04 §5.2）。
- 他の団体がすでに持っているキャラクター（例: 立山博物館のクタベ）は、デザインを流用せず、協業として扱います。**クタベは協業が決まるまで姿を描きません。**
- 社寺の名前や由緒は、了承を得るまで画面にもデータにも出しません（「この地点」と書く）。
- 境内は「お休みの範囲」です。現の旅では出会い・カメラ・会話を止め、夢の旅の箱庭では霧にして中に入れません。社殿・鳥居・宿坊・個人宅は、どちらの旅でも作り込みません。
- 旅印（仮）は御朱印・お守りに似せず、本物の授与品とゲームの進行を結びつけません（§4.5）。
- 立山地獄など、死や地獄にまつわる伝承は「畏れ」の演出には使いますが、茶化しません。
- 伝承の事実は 03 の内容（確度が「確認済」のもの）だけを使い、本作の作り話は【創作】として扱います。画面では、伝承の札（出典と確度つき）と台本の台詞を見分けられるようにします（F-43）。
