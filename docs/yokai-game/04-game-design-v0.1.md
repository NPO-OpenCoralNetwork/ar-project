## 0. この文書の位置づけと用語

3つの設計案と審査を1本にまとめた。**土台は案③**（現地をたどる旅）に、案①の関係づくり（覚えていてくれる、打ち明け話）と案②の手ざわり（札を払う、筆でなぞる）を重ねる。

- **外した案**: 宗教・安全の理由（白鷹や護符の雷鳥に話させる、宝物や布橋の布を妖怪にする、縁起を妖怪のけんかにする、クタベを描いて広める遊び）と、作る量の理由（季節限定の妖怪、住人の移動や毎日の文、音声）。
- 伝承の文はすべて 03（AI が補助した監修前の下書き）が元の仮の文で、公開前に必ず監修を通す（F-71 監修の状態）。
- 02 の数字を読み替える提案は §7-1 にまとめた。

**用語**
| 言葉 | 意味 |
|---|---|
| LLM／台本 | その場で文章を作る AI（雑談だけに使う）／人が書いて監修する固定の文章 |
| 段階0／1 | 01 の AR の段階。0＝カメラなしで和紙の背景に妖怪が出る。1＝カメラの映像に妖怪を重ねる |

## 1. 体験の核

**ピッチ**: 白い曼荼羅帳を手に、昔の立山参詣と同じく、里（富山の町）から麓（岩峅寺・芦峅寺）へ向かう。妖怪は、その場所で立ち止まった人にだけ姿を見せる。仲良くなって悩みをほどくと、伝承を「打ち明け話」として語ってくれる。聞いた話は曼荼羅に色として入り、家に帰ったら今度はあなたが、その話を語る。

**役割「現代の絵解き師（見習い）」**: 芦峅寺の衆徒（しゅと ※読みは監修で確認）は、立山曼荼羅を携えて全国を廻り、絵解きと護符配りをした（#4 立山曼荼羅と衆徒）。プレイヤーは逆向きに、町から麓へ物語を受け取りに行き、持ち帰って語る。手本は夏目友人帳（警戒していた妖怪が、だんだん名前で呼んでくれる）。

| 体験の柱 | 中身 |
|---|---|
| 1. 会うたびに、少し近くなる | 呼び方・好物・前に話したことを覚えている。伝承は仲良くなったご褒美として明かされる |
| 2. 足を止めると、土地が話しかけてくる | 妖怪は立ち止まった人にしか見えない。安全のルールを世界のルールにする |
| 3. 麓で受け取り、家で語る | ピースが「聞いた（線）→その場に立った（色）→妖怪に語った（金）」と育つ |

**仮タイトル案**: ①立山えとき道中（推し） ②えにし絵解き ③ふもとの曼荼羅。

## 2. コアループ

### 2.1 序の口（初回の10分）
| 時間 | 画面と出来事 |
|---|---|
| 0〜2分 | タイトル、役割の一言、文字の大きさ。真っ白な曼荼羅帳が開き、紙から相棒ましろが生まれる【創作】（姿は §7-4 で決める） |
| 2〜4分 | ましろの「三つの約束」（F-60 最初の注意）。①歩きながら画面を見ない ②立入禁止の場所や境内では使わず、夜は出歩かない ③本物のライチョウや動物を追わない。1画面ずつ「わかった」を押す。初回は飛ばせない |
| 4〜6分 | 位置情報の許可を頼む（理由:「気配を出すため。歩いた道は記録しない」）。カメラの許可は段階1を選んだときにだけ頼む。iPhone ではホーム画面への追加を案内（01 の検証結果しだい） |
| 6〜10分 | **現地（里・麓）なら**: 最初の気配→立ち止まる→一言。**家なら**: ましろ【創作】「最初の妖怪は、富山の町で待っている」と言い、「旅の支度」（白描の地図）を見せる |

- 位置を断った人は旅の支度と曼荼羅だけ、カメラを断った人は段階0で遊ぶ。**どこで開いても**（東京の家でも、麓に車で直行しても）ここまでは同じ。

### 2.2 30秒: 立ち止まる → 姿が見える → その場所だけの一言
1. **歩く間は、画面を開いたままポケットに入れておく**（iPhone の Web アプリは表示中しか位置が取れない＝01）。歩く間は地図に動く演出を出さない。近くに気配があると小さな鈴の音だけ鳴る（技術検証で確かめる）。
2. 立ち止まって画面を見ると、近くの気配がまとめて表示される。にじみの中で数秒止まると澄んで、妖怪が現れる。**歩いている間は決して出てこない。**
3. その場所でだけ聞ける台本の一言。例【創作】カーラボーズ「……おい、そこの見習い。ちょっと寄っていけ」
4. 縁の糸が少し締まるか、曼荼羅に線だけのピースが増える。

### 2.3 5分: 1か所でのやりとり
1. **話す**: 本題（伝承・悩み）は台本。合間に LLM で2〜3往復の寄り道ができる。
2. **悩みを進める**（§3.4）。
3. **筆を入れる**: 出来事を終えたピースを指でなぞると色が入る。任意で「まなざし」（画面を伏せて1分、景色を見る）を選ぶと、薄い空の色が重なる。
4. **次へ**: ましろが首を向けて、次の気配の方角を教える。

### 2.4 1回の外出＝1節（20〜40分、3〜5か所）
- 悩みはわざと2か所以上にまたがるように作る（運んでいることは止まったときにだけ見せる）。
- 区切りは「今日はここまで」を押したときか、道中の画面になったとき。そこで「今日の絵解き」（ましろが30秒で振り返り、プレイヤーが3枚選んで一言を添えるカード）。
- 同時に抱える悩みは3つまで。4つ目はましろが【創作】「また今度にしよう」と保留にする。

### 2.5 1日
| 時間帯 | 起きること |
|---|---|
| 朝・昼 | 出会い、悩みごと、札集め |
| 逢魔が時（日の入り30分前〜20分後・案） | 地図が朱から藍へ。影の妖怪「くらがり」が出る。**家でも外でも中身は同じ**で、外にいることへのご褒美はない。道中では出さない。麓では帰り道の案内を優先し、くらがりは駅や家に着いてから出る |
| 夜 | 外では気配だけ（F-62 夜の扱い）。現地で遊んだ日は、その日に会った「なじみ」以上の妖怪が「夜話」に来る（§3.8） |

### 2.6 1回の旅行（ペルソナA: 東京から1泊2日）
| いつ | どこ | すること |
|---|---|---|
| 出発前 | 東京の家 | 序の口（§2.1）と旅の支度 |
| 1日目 昼 | 里・富山駅周辺 | 序章（1節・40分） |
| 移動 | 地鉄など（所要時間・本数は要確認） | 道中。ましろは眠る（F-61 移動中の制限） |
| 1日目 午後 | 麓・岩峅寺 | 第一章（2節、間に休憩） |
| 夕方〜夜 | 富山市内 | 日の入り前に麓を離れる。宿で光蔵坊の夜話 |
| 2日目 | 麓・芦峅寺 | 第二章（2節）・第三章（1節）・終章＋博物館の見学（任意） |
| 帰宅後 | 家 | 稽古で妖怪に語り返す（金の縁取り）。便りで関係が続く |

- **時刻の逆算（仮）**: 12月の日の入りは16時半ごろ。麓では1時間前に帰りを促すので、第一章（約80分）には14時ごろまでに岩峅寺の最初の地点に着く必要がある。富山駅を出る時刻は下見で決める。
- 1泊2日で終章まで届くことを設計の条件にする。どの節も中断・再開できる。1回の旅で「えにし」まで保証するのは、ましろと光蔵坊だけ。

**ペルソナB（富山在住）**: 平日は昼の散歩10〜15分で、近くの川沿いや公園に出る里の妖怪（§3.1 出現の表）と話す。里の悩みは5つで、散歩5〜8回分。その後は雑談・稽古・便りが中心。週末は家族と車で麓へ（速さで判定するので、同乗者も道中は静か）。暗くなってから出かける理由は作らない。

**同行者**: 1台を囲んで遊んでよい。縁と覚え書きは端末の持ち主のもの。

### 2.7 季節
MVP で季節によって変わるのは台詞と便りだけ。行事の日はゲームが一歩下がる。天気とは連動させない（雪や荒天の注意は、麓に入るときの台本の一言で伝える）。
| 時期 | 起きること |
|---|---|
| 3/13 お召し替え（#6） | 了承を得てから前の週に便りで触れる。当日は周辺をお休みに |
| 3〜6月 | ホタルイカ（#21）が里の昼に供物として手に入る。夜の浜へは誘わない |
| 4/8・11/3 前立社壇の例大祭・大祭（§4） | 当日は周辺をお休みに（日付は 03 に確度を付けてから確定） |

## 3. システム

**画面**: 地図 ⇄ 出会い（段階0／1）⇄ 会話 ／ 地図から 縁帳・曼荼羅・設定へ。乗り物では自動で道中画面。家ではおうち画面（雑談・夜話・便り・稽古）から始まる。

### 3.1 出会いと気配
- 出会いの範囲は半径30〜50m（GPS＝衛星で位置を測る仕組みのずれを見込む）。数秒ほぼ動かずにいると澄む。「足を止めた」ボタンは直近数秒の速さを確かめ、歩く速さなら【創作】「止まってから、もう一度」と返す。
- 出会い方は標準とミノモシ（§3.4）の2種類だけ。体を回す操作は求めない。妖怪は切り絵のような板の絵で、段階0と1から選べる（F-10・F-11）。
- **出現の表（F-03 出現ルール）**: 主ストーリーの妖怪は決まった地点に置く（F-04 固定配置）。それとは別に、寄り道の妖怪は場所の種類と時間帯で出る。表はデータで管理する（F-70）。試作では「水辺」1種類だけ作る。

| 場所の種類（里のどこでも） | 昼 | 逢魔が時 | 夜 |
|---|---|---|---|
| 川・用水沿いの歩道（河原には置かない） | ガメ（会ったあと） | くらがり | 気配だけ |
| 公園・遊歩道 | ミノモシ | くらがり | 気配だけ |
| 社寺の境内 | お休み | お休み | お休み |

- 悩みの開始は決まった地点だけ。寄り道の出現では、雑談・供物・語り返しができる。
- **置ける場所（F-05 安全な配置）**: 歩道のある道、広場、公園、公共の空き地だけ。境内・宿坊・住宅の前・河原・歩道のない車道には置かない。下見で「2分立ち止まっても邪魔にならないか」を確かめる。中道坊の「天狗様」（個人の所蔵品 #8）には触れない。市ノ谷・獅子ヶ鼻・美女平・地獄谷・剱岳へは誘導しない。集落では「声をひそめて」と案内する。
- **お休みの範囲**: 境内を地図に登録し、中では出会い・カメラ・会話を止める。語りの地点は境内から50m以上離す（GPS のずれで出入りしないように）。
- **道中と着到**: 歩くより速く動いている間は道中画面。降りて歩き出すと【創作】ましろ「着いたね」。

### 3.2 会話: 台本と LLM の境界
| 台本（監修済み） | LLM（その場で作る） |
|---|---|
| 伝承・史実のすべて、主ストーリー、悩みの始まりと結末、鎮め、終章、安全の言葉、行事の話 | あいさつ、雑談、相づち、プレイヤーの言葉への反応、夜話の続き |
| 画面では出典の印つきの「札」 | 画面ではふつうの「吹き出し」 |

- **LLM で話せるのは7体**（光蔵坊・ガメ・カーラボーズ・ミノモシ・古笠・紙魚の文六・ちぐさ）。ましろ・お糸・くらがり・クタベ・雷鳥は台本だけ。
- **LLM に渡してよい札**（ほかは渡さない）:

| 妖怪 | 渡す札 | 渡さない札 |
|---|---|---|
| 光蔵坊 | #8 | #2・#11（神仏・剱岳） |
| ガメ・カーラボーズ | #18 | 売薬・麓の薬の札 |
| ミノモシ | #17 | ― |
| 紙魚の文六 | #4（曼荼羅と衆徒の絵解き） | #1 縁起、#9 疫病、§3-C |
| ちぐさ | §3-C2（確度が付いてから） | #9 |
| 7体共通 | 供物の札（#21〜#23 の確認済の部分） | #3 地獄、#5〜#7 女人禁制、#10 雷鳥 |

- **渡すもの**: 性格と口調、縁の段階、相関表（固定）、覚え書き、上の札。夜話では「その日の出来事（どこで会ったか、何を渡したか）」だけを足し、札の中身を聞かれたら札をそのまま出す。
- **きまり**: 伝承は言い換えない。札にないことは【創作】「わしは知らん。博物館で確かめてみるといい」。神仏を代弁しない。相関表にない関係や約束を作らない。夜の外出・立入禁止の場所・ライチョウへの接近を勧めない。体の不調には「お医者さんに」。電波が弱いときは台本に切り替える。
- **入力の扱い（F-22・F-23）**: 選択肢が基本で、自由入力は1回40字まで。悪口・不適切な語・電話番号や住所らしきものは LLM に送らず、台本の返事【創作】「その話は、わしにはよく分からん」にする。話題がその妖怪の性格・悩み・相関表・渡した札から外れたら、決まった台詞で戻す。判定の仕方は技術検証で試す。
- **出す前のチェック**: ①札にない年号・地名・人名・神仏名が混じった返事は、台本の決まり文句に差し替える（覚え書きに入っている語は通す）。②雷鳥と「権現・雄山神・伊邪那岐・阿弥陀」が同じ返事に出たら差し替える。
- **記録**: テスト中だけ、同意をとって会話を記録する。名前・地名は伏せ、テスト終了から3か月で消す（案）。監修者が抜き取りで「伝承と違う発言0件」を確かめる。位置は記録しない（F-52 位置情報の最小化）。
- **話し疲れ（F-22）**: 残り回数は数字で見せず、妖怪があくびをして【創作】「今日はよく話した。続きはまた明日」。使い切っても台本・札・便りは続く。テストでは招待コードごとに数え、公開に備えて「サービス全体の1日の上限」も置く。
- **費用**: 1往復で渡す文章は約3,000字、返事は約100字。1人1日20往復なら、11月の試作（8人×8日）で最大約1,300往復、3月のテスト（20人×14日）で最大5,600往復。モデルの単価は技術検証で決まる（§7-6）。
- **覚え書き（H3 の要）**: 決まった欄（呼び名、出身、好きな食べ物）だけ。端末に保存し、話すときだけ一時的に送る。縁帳で見て消せる。自動抽出は試作のあとで判断。例【創作】光蔵坊「東京から来たと言っていたな。向こうには、こんな山はなかろう」

### 3.3 縁
数字では見せず、糸の形で見せる（F-24 縁）。**縁は下がらず**、会えない日が続いても罰はない。連続ログインのご褒美も作らない。

| 段階 | 見た目 | なる条件 | 変わること | 例: 光蔵坊【創作】 |
|---|---|---|---|---|
| 気配 | 糸くず | ― | 地図のにじみだけ | 木の葉がざわつく |
| 顔見知り | 一本の糸 | 現地で会う | 名乗る。呼び方は「人の子」 | 「なんじゃ、わしが見えるのか」 |
| なじみ | より糸 | 悩みを1つ解く／好物を渡す（現地） | 呼び方が「見習い」に。家で話せる・夜話に来る | 「昆布というのを知っておるか。いや、別に……」 |
| 語り仲間 | 組紐 | 主な悩みを解く（現地） | 名前で呼ぶ。覚え書きで気づかう | 「おう、〇〇。今日も歩くか」 |
| えにし | 結び目 | ゆかりの地点で最後の打ち明け話（現地だけ） | 曼荼羅に姿が描かれる | 「この話は、ここでしか話さん」 |

- 主ストーリーの妖怪は章の出来事で一気に深まり、寄り道の妖怪は少しずつ深まる。**会話では段階は上がらない**（話す回数をこなす作業にしないため。F-24 の読み替え）。代わりに糸の艶が少し増え、便りの文面が変わる。段階には文字のラベルも付ける。
- **ましろ**は縁の段階を持たない相棒。章が進むと呼び方が変わり、終章でえにしになる。
- **縁帳**: 薬売りの懸場帳（お得意先の帳面、#20 の案）が手本。「伝承の部分（出典つき）」と「本作の創作」を分けて見せ、オリジナルの妖怪は「本作オリジナル」と明記。

### 3.4 悩みごと3型
| 型 | すること | 例 |
|---|---|---|
| 調べる | その地点に立つと札が出る。家では「どこにあるか」までしか分からない | 紙魚の虫食いの頁を4か所で取り戻す |
| 届ける | 物・伝言・妖怪を運ぶ | 古笠を岩峅寺から芦峅寺へ |
| とりもつ | 二体の言い分を聞き、伝え方を選んで引き合わせる | ガメとカーラボーズ |

- 失敗はなく、選び方で台詞が変わるだけ。悩みの開始と解決は現地だけ。**例外**: くらがりの悩み（家でも解ける）。
- **ミノモシ（番外）**: 光は払うほど増える（#17 の伝承）。ゲームでは【創作】の遊び方として「払わずに待つ」と離れていく。そのあと札で伝承を出す:「払うほど増える」「漁師は嵐の前ぶれとした」「曲尺（かねじゃく）を腰に差すと逃れられるという」。ましろ【創作】「昔の人は、曲尺を腰に差したそうだ」。
- 全15個の一覧は付録A。

### 3.5 鎮め（MVPで1種類）
**「絵解き鎮め」1種類**。F-31（鎮め）は Should なので、**演出を外しても成り立つ形**にする。中身は「札を並べる」仕組みで、鎮めはそれに渦と風の演出を足したもの。外したら稽古と同じ形で、第一章はそのまま進む。

**1回の流れ（光蔵坊、1〜2分）**
1. 墨の渦の中に「光蔵坊の話」の題が筆文字で出る。
2. 手札（「調べる」で拾った札3枚）から、話の順に1枚ずつ選んで指で払う。
3. 合っていれば鈴が鳴り、渦が1段引く。違えば渦が少し濃くなり、ましろがヒントをくれる（点数・打ち切りはない）。
4. 3枚が正しく並ぶと渦が消え、光蔵坊【創作】「……そうじゃ。それが、わしの話じゃ」。

**札（#8 の範囲）**: ①智明坊が、おごり高ぶって天狗になった ②光蔵坊と名乗り、市ノ谷に棲んだ ③刀尾権現に追い出された。鎮めのあと、えにしの打ち明け話として ④「『和漢三才図会』(1712) には、そのとき落とした爪が立山権現の本社の宝物になったと書かれている」が開く。
- 絵は、追い出されて去る**光蔵坊の後ろ姿だけ**。刀尾権現は描かず、風と光で表す。
- **拾い漏れの救い**: 拾っていない札は白紙で出る。白紙でも、ましろがその部分を代わりに語って最後まで進める。そのピースは白描のまま、拾い漏れの地点は「次の楽しみ」として地図に残る。
- 「光蔵坊が今も荒ぶっている」は【創作】（#8 は追い出されたところで終わる）。使う相手は荒ぶる妖怪だけ。緊張は「場所の畏れ」（昼の公道で風が強まり、画面が藍に沈む）で出す。
- **雷鳥の札と、立山権現・阿弥陀如来の札は、同じ頁・同じ手札・同じ絵解きカードに入れない**（03 §3-A。二つをつなげると根拠のない「雷鳥は立山権現の使い」になる）。

### 3.6 立山曼荼羅（収集）
- 本作の曼荼羅は、里・麓・山に合わせた【創作】の構図の縦長の掛軸（下段＝里、中段＝麓、上段＝山・霧の中）。本物の立山曼荼羅に描かれたもの（開山・地獄・浄土・登拝の道・布橋灌頂会 #4）は札で別に紹介する。実物の画像は使わない。神仏は光・雲・山の形で表す。
- ピースの状態（色に加えて形の印と文字で示す）: **空白**→**白描**（話を聞いた。家・噂・夢）→**彩色**（その地点に立ち、筆を入れた。現地だけ）→**金の縁取り**（稽古で妖怪に語り返した。彩色済みのピースだけ）。現実の人に話したかどうかは判定しない。カードの外への共有は条件にしない。
- 例外: くらがりのピースは「時間のピース」で、逢魔が時に出会えばどこでも色が入る。
- 白描は色付きの絵から自動で作る。ピースをタップすると札（出典・確度つき、F-43 出典の表示）が開き、白描なら「ここに立てば色が入る」地図が出る。
- **絵解きカード**: 3枚を並べて一言を添える。台本の文とプレイヤーのひと言は別の書体にし、護符や御朱印に似せない。
- **クタベの札・ピースは、文字と薬草の景色だけにして姿を描かない。** 協業が決まったら館の公式キャラクターで差し替える。
- 全体で約24ピース（里5・麓15・終章2・山の予告2〜4）。

### 3.9 時間帯
- 日の出・日の入りは端末の中で計算する。逢魔が時は「逢魔が時」の文字と風の音でも伝える（色だけにしない）。

- テスト用に時刻の手動切り替えを付ける。暦はデータの形だけ決め、MVP では 3/13・4/8・11/3 だけ入れる。

## 5. トーンと表現のルール

### 5.1 やさしさと畏れ
- **やさしさ（基調）**: 昼の出会い・関係づくり・家。和紙の明るい色、鈴の音、呼び名が変わる。罪悪感で呼び戻さない。
- **畏れ（ときどき）**: 逢魔が時、光蔵坊が荒ぶる場所、地獄の頁。色が沈み、風の音、口調が低くなる。驚かせる演出はせず、【創作】くらがり「こわがらなくていい。話すだけだ」のように、やさしさで閉じる。

### 5.2 神仏・宗教・繊細な題材
| 題材 | ルール |
|---|---|
| 神仏 | キャラクターにせず、代弁しない。妖怪は「あのお方」「山の神さま」と呼ぶ。絵では光・雲・山の形 |
| 雷鳥 | 「立山の神さまの使い」に固定し、「山の神さま」「あのお方」と結びつけない。護符の効き目は語らない |
| 縁起 | ましろを開山の白鷹として話させない。地名の由来話は札にしない（明治以降の書き直しがある #1） |
| 女人禁制・布橋灌頂会・姥尊 | 良いことのように描かず、今も続く儀礼を批判もしない。姥尊は姿を見せない。道順をなぞらせず、目隠しを真似させない。奪衣婆の面は怖く描きすぎない（#6）。お糸の姿と贈り物（白い糸）は、糸・布・衣を思わせない案（絵筆の毛、墨）も用意して当事者に確認する。札は監修と当事者（布橋灌頂会実行委員会・芦峅女性の会・雄山神社）の了承まで公開しない |
| 地獄（#3） | 茶化さない。亡くなった人を集める対象にせず、第三章と切り離す |
| 疫病（#9） | 「告げたとされる」話にとどめる。共有を疫病よけに重ねない。薬の効き目や予言との因果は語らない |
| 確度 | 使うのは「確認済」だけ。03 の §3（知識の連鎖）・§4（暦）は確度ラベルがないので、Claude が11月中に 03 へラベルを付け足すまで「要確認」として札にしない（公的な出典なので確認済になる見込み）。§5 は使わない。閻魔堂の像の指定区分は語らない。#13 は使わない。「刀尾権現と刀尾天神剱岳神は同じか」は監修まで言い切らない |
| 見た目・施設・読み | 護符・御朱印に似せない。社寺名や由緒は了承前は出さず「この地点」と書く。神仏名・地名・人名のふりがな一覧を作り監修に回す |
