## 0. この文書の位置づけと用語

3つの設計案と審査を1本にまとめたものです。**土台は案③**（現地をたどる旅）に、案①の関係づくり（覚えていてくれる、打ち明け話）と案②の手ざわり（札を払う、筆でなぞる）を重ねています。v0.2 で、その上に「夢の旅」（家の3Dの箱庭）を足しました。

- **外した案**: 宗教・安全の理由（白鷹や護符の雷鳥に話させる、宝物や布橋の布を妖怪にする、縁起を妖怪のけんかにする、クタベを描いて広める遊び）と、作る量の理由（季節限定の妖怪、住人の移動や毎日の文、音声）。
- 伝承の文はすべて 03（AI が補助した監修前の下書き）が元の仮の文で、公開前に必ず監修を通します（F-71 監修の状態）。
- 02 の数字の読み替え（§7 #1）は 10/17 に決まり、02 v0.2 §4.3 に反映しました。

## 1. 体験の核

**ピッチ**: 白い曼荼羅帳を手に、昔の立山参詣と同じく、里（富山の町）から麓（岩峅寺・芦峅寺）へ向かいます。家では、立山の3Dの箱庭を歩いて、妖怪の夢の姿に会い、物語を聞きます。現地では、同じ場所に本当に立って、その妖怪に「再会」します。仲良くなって悩みをほどくと、伝承を「打ち明け話」として語ってくれます。聞いた話は曼荼羅に線として入り、現地に立つと色が入ります。家に帰ったら今度はあなたが、その話を語ります。

**役割「現代の絵解き師（見習い）」**: 芦峅寺の衆徒（しゅと ※読みは監修で確認）は、立山曼荼羅を携えて全国を廻り、絵解きと護符配りをしました（#4 立山曼荼羅と衆徒）。プレイヤーは逆向きに、町から麓へ物語を受け取りに行き、持ち帰って語ります。夢の旅は、遠くの人が絵解きで立山を受け取った体験に、現の旅は、実際に参詣に行く体験に重なります。手本は夏目友人帳（警戒していた妖怪が、だんだん名前で呼んでくれる）です。

| 体験の柱 | 中身 |
|---|---|
| 1. 会うたびに、少し近くなる | 呼び方・好物・前に話したことを覚えている。伝承は仲良くなったご褒美として明かされる |
| 2. 足を止めると、土地が話しかけてくる | 現地では、妖怪は立ち止まった人にしか見えない。安全のルールを世界のルールにする。家では、名所で耳を澄ました人にだけ夢の姿が浮かぶ |
| 3. 夢で会い、麓で再会し、家で語る | ピースが「聞いた（線）→その場に立った（色）→妖怪に語った（金）」と育つ。家で先に会った妖怪は、現地で【創作】「夢で見た顔だな……本当に来たのか」と迎える |

**仮タイトル案**: ①立山えとき道中（推し） ②えにし絵解き ③ふもとの曼荼羅。

### 1.1 二つの旅（05 §3。最初に公開して、後から削らない）

| | 夢の旅（家・PC／スマホ） | 現の旅（現地・スマホ） |
|---|---|---|
| 入り方 | 地域を選ぶ → その土地の3Dの箱庭に入る | 現地で GPS の地図を開く |
| 動き方 | アバター（絵解き師の見習い）と相棒のましろで歩く。名所で「指を置いて耳を澄ます」と、数秒で妖怪の姿が浮かぶ | 自分の足で歩く。立ち止まると妖怪が現れる |
| 妖怪の姿 | 白描の「夢の姿」 | 色のついた本当の姿 |
| 会話 | 台本。段階6から、「なじみ」以上の妖怪と端末内 LLM の雑談 | 台本（段階6から LLM の雑談）。本人がその場所でだけ話す台詞がある |
| 悩みごと・鎮め | 家でも始めて、解ける | 現地でも始めて、解ける |
| 物語 | **最後まで進められる**（箱庭のない場所の遊び方は §3.8 の案。PO の確認待ち）。打ち明け話は、古笠の便りやましろの「また聞き」として読める | 同じ打ち明け話を、妖怪本人がゆかりの地点で語る |
| 縁 | 「顔見知り」→「なじみ」まで | 「語り仲間」「えにし」まで上がる |
| 曼荼羅 | 白描（線）まで | 色が入る。家で語り返すと金の縁取り |
| 行った証 | 枠だけ見える | 日付入りの「旅印（仮）」 |

1. 家の遊びを不利にして現地へ行かせるのではなく、現地で上乗せします。
2. 物語の本編は、現地に行かなくても最後まで遊べます（遠くに住む人、行けない事情のある人のため）。
3. 現地でしか手に入らないのは「色・語り仲間とえにし・旅印・その場でしか聞けない台詞」です。
4. 一度配ったものは後から取り上げません。家でできることは、控えめに始めて広げる方向にだけ動かします。

## 2. コアループ

### 2.1 序の口（初回の10分）
| 時間 | 画面と出来事 |
|---|---|
| 0〜2分 | タイトル、役割の一言、文字の大きさ。真っ白な曼荼羅帳が開き、紙から相棒ましろが生まれる【創作】（姿は白い紙の鳥。§7 #4） |
| 2〜4分 | ましろの「三つの約束」（F-60 最初の注意）。①歩きながら画面を見ない ②立入禁止の場所や境内では使わず、夜は出歩かない ③本物のライチョウや動物を追わない。1画面ずつ「わかった」を押す。初回は飛ばせない（家で始めた人にも見せる。いつか現地へ行く日のため） |
| 4〜6分 | 「夢の旅（家で）」か「現の旅（現地で）」を選ぶ。**現の旅**: 位置情報の許可を頼む（理由:「気配を出すため。歩いた道は記録しない」）。カメラの許可は AR 段階1を選んだときにだけ頼む。iPhone ではホーム画面への追加を案内（01 の検証結果しだい）。**夢の旅**: 位置情報もカメラも使わないので、許可は頼まない。地域を選ぶ（MVP は立山だけ） |
| 6〜10分 | **現の旅（里・麓）**: 最初の気配→立ち止まる→一言。**夢の旅**: 岩峅寺の箱庭に入る（はじめては昼）。ましろ【創作】「ここは夢の中の麓。耳を澄ますと、誰かいる」。最初の気配まで歩き、名所に指を置いて耳を澄ますと、第一章の最初の妖怪の夢の姿が浮かぶ |

- 位置を断った人は夢の旅と曼荼羅で、カメラを断った人は AR 段階0で遊べます。**どこで開いても**（東京の家でも、麓に車で直行しても）、最初の妖怪に会うところまで進めます。

### 2.2 30秒: 立ち止まる（耳を澄ます）→ 姿が見える → その場所だけの一言

**現の旅**
1. **歩く間は、画面を開いたままポケットに入れておく**（iPhone の Web アプリは表示中しか位置が取れない＝01）。歩く間は地図に動く演出を出さない。近くに気配があると小さな鈴の音だけ鳴る（段階0.5 の GPS の検証で確かめる）。
2. 立ち止まって画面を見ると、近くの気配がまとめて表示される。にじみの中で数秒止まると澄んで、妖怪が色のついた姿で現れる。**歩いている間は決して出てこない。**
3. その場所でだけ聞ける台本の一言。例【創作】カーラボーズ「……人の子か。足で来たか」（「見習い」と呼ぶのは仲直りのあと。§3.3）。夢で先に会っていれば【創作】「夢で見た顔だな……本当に来たのか」。
4. 縁の糸が少し締まるか、曼荼羅に色の入ったピースが増える。

**夢の旅**
1. 箱庭をアバターとましろで歩く。気配は、地面の墨のにじみと小さな鈴の音で示す。**歩いている間は出てこない。**
2. 名所（現地の地点と同じ場所）で止まり、指を置いて耳を澄ます。数秒で、白描の夢の姿が浮かぶ。
3. 短い台本の一言。
4. 縁の糸が少し締まるか、曼荼羅に線だけのピースが増える。

### 2.3 5分: 1か所でのやりとり
1. **話す**: 本題（伝承・悩み）は台本。3月のテストまでは、寄り道も台本の選択肢で作る。段階6から、「なじみ」以上の妖怪とは合間に端末内 LLM で2〜3往復の寄り道ができる。
2. **悩みを進める**（§3.4）。
3. **筆を入れる**: 出来事を終えたピースを指でなぞる。現地では色が入り、家では線（白描）が入る。現地では任意で「まなざし」（画面を伏せて1分、景色を見る）を選ぶと、薄い空の色が重なる。
4. **次へ**: ましろが首を向けて、次の気配の方角を教える。

### 2.4 1回の外出＝1節（20〜40分、3〜5か所）
- 悩みはわざと2か所以上にまたがるように作る（運んでいることは止まったときにだけ見せる）。
- 区切りは「今日はここまで」を押したときか、道中の画面になったとき。そこで「今日の絵解き」（ましろが30秒で振り返り、プレイヤーが3枚選んで一言を添えるカード）。現地で節を終えると、旅印（仮）を押せる（§3.11）。
- 同時に抱える悩みは3つまで。4つ目はましろが【創作】「また今度にしよう」と保留にする。
- 夢の旅も、同じ節を単位にする。どの節も中断・再開できる。

## 3. システム

**画面**: 
- 現の旅: 地図 ⇄ 出会い（AR 段階0／1）⇄ 会話 ／ 地図から 縁帳・曼荼羅・設定へ。乗り物では自動で道中画面。

### 3.1 出会いと気配
- **現の旅**: 出会いの範囲は半径30〜50m（GPS＝衛星で位置を測る仕組みのずれを見込む）。数秒ほぼ動かずにいると澄む。「足を止めた」ボタンは直近数秒の速さを確かめ、歩く速さなら【創作】「止まってから、もう一度」と返す。
- **夢の旅**: 名所で指を置いて耳を澄ますと、数秒で夢の姿が浮かぶ。アバターが歩いている間は出てこない。箱庭の妖怪の位置は、現地の地点と同じにする。地点の数は増やさない（にぎやかさは、地点を近づけて描く写し方で出す。05 §4.1）。
- 出会い方は、現地では標準とミノモシ（§3.4）の2種類だけ。体を回す操作は求めない。妖怪は切り絵のような板の絵のまま（夢では白描、現地では彩色）。現地では AR 段階0と1から選べる（F-10・F-11）。
- **出現の表（F-03 出現ルール）**: 主ストーリーの妖怪は決まった地点に置く（F-04 固定配置）。それとは別に、寄り道の妖怪は場所の種類と時間帯で出る。表はデータで管理する（F-70）。試作では「水辺」1種類だけ作る。夢の旅でも同じ表を使う。

| 場所の種類（里のどこでも） | 昼 | 逢魔が時 | 夜 |
|---|---|---|---|
| 川・用水沿いの歩道（河原には置かない） | ガメ（会ったあと） | くらがり | 気配だけ |
| 公園・遊歩道 | ミノモシ | くらがり | 気配だけ |
| 社寺の境内 | お休み | お休み | お休み |

- 悩みの開始は決まった地点だけ。寄り道の出現では、雑談・供物・語り返しができる。
- **置ける場所（F-05 安全な配置）**: 歩道のある道、広場、公園、公共の空き地だけ。境内・宿坊・住宅の前・河原・歩道のない車道には置かない。下見で「2分立ち止まっても邪魔にならないか」を確かめる。箱庭でも同じ地点に置くので、家並みの前（仮の家並みを含む）には置かない。中道坊の「天狗様」（個人の所蔵品 #8）には触れない。市ノ谷・獅子ヶ鼻・美女平・地獄谷・剱岳へは誘導しない。集落では「声をひそめて」と案内する。
- **お休みの範囲**: 境内を地図に登録し、現の旅では中で出会い・カメラ・会話を止める。語りの地点は境内から50m以上離す（GPS のずれで出入りしないように）。夢の旅の箱庭では、境内を霧にして中に入れない（社殿・鳥居は描かない。06 §3.10）。
- **道中と着到**: 歩くより速く動いている間は道中画面。降りて歩き出すと【創作】ましろ「着いたね」。

### 3.2 会話: 台本と LLM の境界
**作る順番**: 3月のテストまでは、会話はすべて台本で作ります。LLM は作る順番の最後（段階6、3月のテストの後）に、**端末内の Gemma 4（E2B／E4B）**で足します（10/17 決定）。クラウドの API は使わないので、LLM の中継サーバー・API のアカウント・従量課金は要りません。下の境界と安全策は、端末内 LLM にもそのまま当てはめます。

| 台本（監修済み） | LLM（段階6から。その場で作る） |
|---|---|
| 伝承・史実のすべて、主ストーリー、悩みの始まりと結末、鎮め、終章、安全の言葉、行事の話 | あいさつ、雑談、相づち、プレイヤーの言葉への反応、夜話の続き |

**画面での見分け方**（F-43）: 次の3つを、枠と書体ではっきり分けます。
| 種類 | 見せ方 |
|---|---|
| 伝承の札（03 の事実。監修済み） | 札の枠。出典と確度の印を必ず付ける |
| 台本の台詞（【創作】） | ふつうの吹き出し |
| LLM の雑談（段階6から） | 吹き出しに小さな「その場の言葉」の印。札の枠は使わない |

- **LLM で話せるのは7体**（光蔵坊・ガメ・カーラボーズ・ミノモシ・古笠・紙魚の文六・ちぐさ）で、縁が「なじみ」以上になってから。**家でも現地でも**話せる。ましろ・お糸・くらがり・クタベ・雷鳥は台本だけ。
- **LLM に渡してよい札**（ほかは渡さない）:

| 妖怪 | 渡す札 | 渡さない札 |
|---|---|---|
| 光蔵坊 | #8 | #2・#11（神仏・剱岳） |
| ガメ・カーラボーズ | #18 | 売薬・麓の薬の札 |
| ミノモシ | #17 | ― |
| 紙魚の文六 | #4（曼荼羅と衆徒の絵解き） | #1 縁起、#9 疫病、§3-C |
| ちぐさ | §3-C2（確度が付いてから） | #9 |

- **渡すもの**: 性格と口調、縁の段階、相関表（固定）、覚え書き、上の札。夜話では「その日の出来事（どこで会ったか、何を渡したか、夢か現地か）」だけを足し、札の中身を聞かれたら札をそのまま出す。
- **きまり**: 伝承は言い換えない。札にないことは【創作】「わしは知らん。博物館で確かめてみるといい」。神仏を代弁しない。相関表にない関係や約束を作らない。夜の外出・立入禁止の場所・ライチョウへの接近を勧めない。体の不調には「お医者さんに」。モデルが読み込めないときや端末が対応していないときは台本に切り替える。
- **入力の扱い（F-22・F-23）**: 3月のテストまでは選択肢だけ。段階6で自由入力（1回40字まで）を足す。悪口・不適切な語・電話番号や住所らしきものは LLM に渡さず、台本の返事【創作】「その話は、わしにはよく分からん」にする。話題がその妖怪の性格・悩み・相関表・渡した札から外れたら、決まった台詞で戻す。判定の仕方は段階6で試す。
- **出す前のチェック**: ①札にない年号・地名・人名・神仏名が混じった返事は、台本の決まり文句に差し替える（覚え書きに入っている語は通す）。②雷鳥と「権現・雄山神・伊邪那岐・阿弥陀」が同じ返事に出たら差し替える。
- **記録**: 段階6のテスト中だけ、同意をとって会話を記録する。名前・地名は伏せ、テスト終了から3か月で消す（案）。監修者が抜き取りで「伝承と違う発言0件」を確かめる。位置は記録しない（F-52 位置情報の最小化）。
- **話し疲れ**: 費用のための回数の上限は要らなくなった。端末の発熱・電池と、台本の価値が薄まらないようにするために上限を置くかは、段階6で決める。置く場合も、残り回数は数字で見せず、妖怪があくびをして【創作】「今日はよく話した。続きはまた明日」。使い切っても台本・札・便りは続く。
- **端末内 LLM の条件（段階6で決める）**: メモリ8GB程度が目安（E2B。要確認）。WebGPU（iOS 26 の Safari から標準で有効）で動かすか、アプリの殻に包むかは、iPhone で測って決める。モデルのダウンロード（約2GB）を、どこで・いつしてもらうかも決める。会話の速さの目標も、そのときに決め直す。
- **覚え書き（H3 の要）**: 決まった欄（呼び名、出身、好きな食べ物）だけ。端末に保存し、引き継ぎ（F-51）のときだけサーバーに預ける。縁帳で見て消せる。3月のテストまでは、呼び名を台本に差し込む形で使う。自動抽出は段階6のあとで判断。例【創作】光蔵坊「東京から来たと言っていたな。向こうには、こんな山はなかろう」

### 3.3 縁
数字では見せず、糸の形で見せる（F-24 縁）。**縁は下がらず**、会えない日が続いても罰はない。連続ログインのご褒美も作らない。**家（夢の旅）で上がるのは「なじみ」まで**で、「語り仲間」「えにし」は現地で上がる。

| 段階 | 見た目 | なる条件 | 変わること | 例: 光蔵坊【創作】 |
|---|---|---|---|---|
| 気配 | 糸くず | ― | 地図・箱庭のにじみだけ | 木の葉がざわつく |
| 顔見知り | 一本の糸 | 会う（家の夢の姿でも、現地でも） | 名乗る。呼び方は「人の子」 | 現地ではじめて: 「なんじゃ、わしが見えるのか」／夢で: 「……夢の中まで来おったか」 |
| なじみ | より糸 | 悩みを1つ解く／好物を渡す（家でも現地でも） | 呼び方が「見習い」に。夜話に来る。段階6から LLM の雑談 | 「昆布というのを知っておるか。いや、別に……」 |
| 語り仲間 | 組紐 | 主な悩みを解いたうえで、現地で本人に会う（悩みは家で解いていてもよい） | 名前で呼ぶ。覚え書きで気づかう | 「おう、〇〇。今日も歩くか」 |
| えにし | 結び目 | ゆかりの地点で最後の打ち明け話を本人から聞く（現地だけ） | 曼荼羅に姿が描かれる | 「この話は、ここでしか話さん」 |

- 家で先に「なじみ」になっていた妖怪に現地で会うと、【創作】「夢で見た顔だな……本当に来たのか」と再会の台詞が入る。
- 主ストーリーの妖怪は章の出来事で一気に深まり、寄り道の妖怪は少しずつ深まる。**会話では段階は上がらない**（話す回数をこなす作業にしないため。F-24）。代わりに糸の艶が少し増え、便りの文面が変わる。段階には文字のラベルも付ける。
- **ましろ**は縁の段階を持たない相棒。章が進むと呼び方が変わり、現地の終章でえにしになる（§4.2）。
- **縁帳**: 薬売りの懸場帳（お得意先の帳面、#20 の案）が手本。「伝承の部分（出典つき）」と「本作の創作」を分けて見せ、オリジナルの妖怪は「本作オリジナル」と明記。

### 3.4 悩みごと3型
| 型 | すること | 例 |
|---|---|---|
| 調べる | その地点に立つ（家では、箱庭の同じ地点で耳を澄ます）と札が出る | 紙魚の虫食いの頁を4か所で取り戻す |
| 届ける | 物・伝言・妖怪を運ぶ | 古笠を岩峅寺から芦峅寺へ |
| とりもつ | 二体の言い分を聞き、伝え方を選んで引き合わせる | ガメとカーラボーズ |

- 失敗はなく、選び方で台詞が変わるだけ。**悩みは家でも現地でも始めて、解ける**（05 §3）。家で解いた悩みは、現地でやり直さなくてよい。現地では、その地点で本人が話す台詞と色が加わる。
- **ミノモシ（番外）**: 体につき、手で払うといっそう増える（#17 の伝承）。光として描くのと、「払わずに待つ」と離れていく遊び方は【創作】（原典に「光」の語はない）。そのあと札で伝承を出す（札の文は `lore-cards.json` の mino-1〜3 が正: 体について払うと増える／漁師は天気が荒れる前ぶれとした／腰に曲尺（かねじゃく）を差すと難を逃れる）。ましろ【創作】「昔の人は、曲尺を腰に差したそうだ」。
- 全15個の一覧は付録A。

### 3.5 鎮め（MVPで1種類）
**「絵解き鎮め」1種類**。F-31（鎮め）は Should なので、**演出を外しても成り立つ形**にする。中身は「札を並べる」仕組みで、鎮めはそれに渦と風の演出を足したもの。外したら稽古と同じ形で、第一章はそのまま進む。**家でも現地でもできる。**

**1回の流れ（光蔵坊、1〜2分）**
1. 墨の渦の中に「光蔵坊の話」の題が筆文字で出る。
2. 手札（「調べる」で拾った札3枚）から、話の順に1枚ずつ選んで指で払う。
3. 合っていれば鈴が鳴り、渦が1段引く。違えば渦が少し濃くなり、ましろがヒントをくれる（点数・打ち切りはない）。
4. 3枚が正しく並ぶと渦が消え、光蔵坊【創作】「……そうじゃ。それが、わしの話じゃ」。

**札（#8 の範囲）**: ①智明坊が、おごり高ぶって天狗になった ②光蔵坊と名乗り、市ノ谷に棲んだ ③刀尾権現に追い出された（段階2の試作では、①と②を1枚の札「おごり高ぶった智明坊が天狗になり、光蔵坊と名乗って市ノ谷に棲んだ。」にした。①だけでは、光蔵坊との会話で別の人の話に読めるため。03 #8 の文のまま。③の刀尾権現の部分は入れていない。札の分け方は PO と監修で確かめる）。鎮めのあとに ④「『和漢三才図会』(1712) には、そのとき落とした爪が立山権現の本社の宝物になったと書かれている」が開く。**現地では**、光蔵坊本人がゆかりの地点でえにしの打ち明け話として語る。**家では**、古笠の便りかましろの「また聞き」（白描の頁）として読める。
- 絵は、追い出されて去る**光蔵坊の後ろ姿だけ**。刀尾権現は描かず、風と光で表す。光蔵坊は刀尾権現を「あのお方」としか呼ばない。
- **拾い漏れの救い**: 拾っていない札は白紙で出る。白紙でも、ましろがその部分を代わりに語って最後まで進める。そのピースは白描のまま、拾い漏れの地点は「次の楽しみ」として地図（箱庭）に残る。
- 「光蔵坊が今も荒ぶっている」は【創作】（#8 は追い出されたところで終わる）。使う相手は荒ぶる妖怪だけ。緊張は「場所の畏れ」（昼の公道で風が強まり、画面が藍に沈む）で出す。
- **雷鳥の札と、立山権現・阿弥陀如来の札は、同じ頁・同じ手札・同じ絵解きカードに入れない**（03 §3-A。二つをつなげると根拠のない「雷鳥は立山権現の使い」になる）。

### 3.6 立山曼荼羅（収集）
- 本作の曼荼羅は、里・麓・山に合わせた【創作】の構図の縦長の掛軸（下段＝里、中段＝麓、上段＝山・霧の中）。本物の立山曼荼羅に描かれたもの（開山・地獄・浄土・登拝の道・布橋灌頂会 #4）は札で別に紹介する。実物の画像は使わない。神仏は光・雲・山の形で表す。
- ピースの状態（色に加えて形の印と文字で示す）: **空白**→**白描**（話を聞いた。家・噂・夢）→**彩色**（その地点に立ち、筆を入れた。現地だけ）→**金の縁取り**（稽古で妖怪に語り返した。彩色済みのピースだけ）。現実の人に話したかどうかは判定しない。カードの外への共有は条件にしない。
- 例外: くらがりのピースは「時間のピース」で、逢魔が時に出会えばどこでも（家でも）色が入る。
- 白描は色付きの絵から自動で作る。ピースをタップすると札（出典・確度つき、F-43 出典の表示）が開き、白描なら「ここに立てば色が入る」地図が出る。
- **白描→彩色を、景色の見た目の切り替えにも使う**（06 §5）。夢の旅の箱庭は「光と霞」が標準で、白描の見た目にも切り替えられる。段階2の後に、まだ訪れていない場所を白描で淡く見せ、歩いた所から色づく演出（06 §5 案B）を入れる。これは**景色の演出**で、曼荼羅のピースの彩色（現地だけ）とは別のもの。箱庭の妖怪は、景色が色づいても白描の夢の姿のまま。現の旅の地図では、現地で色を入れた地点の札に色が入る。
- **絵解きカード**: 3枚を並べて一言を添える。台本の文とプレイヤーのひと言は別の書体にし、護符や御朱印に似せない。
- **クタベの札・ピースは、文字と薬草の景色だけにして姿を描かない。** 協業が決まったら館の公式キャラクターで差し替える。
- 全体で約24ピース（里5・麓15・終章2・山の予告2〜4）。

### 3.9 時間帯
- 日の出・日の入りは端末の中で計算する。逢魔が時は「逢魔が時」の文字と風の音でも伝える（色だけにしない）。
- 麓（現の旅）では日の入りの1時間前から「暗くなるまで あと○分／駅まで歩いて ○分」を表示し、逢魔が時が始まると出会いを止める（ましろ【創作】「暗くなる前に帰ろう」）。
- 夢の旅の箱庭は、はじめて入ったときは昼。昼・夕・夜の見た目は 06 §2 のパレットを使う。
- テスト用に時刻の手動切り替えを付ける。暦はデータの形だけ決め、MVP では 3/13・4/8・11/3 だけ入れる。

## 5. トーンと表現のルール

### 5.1 やさしさと畏れ
- **やさしさ（基調）**: 昼の出会い・関係づくり・家。和紙の明るい色、金色の午後の光（06）、鈴の音、呼び名が変わる。罪悪感で呼び戻さない。
- **畏れ（ときどき）**: 逢魔が時、光蔵坊が荒ぶる場所、地獄の頁。色が沈み、風の音、口調が低くなる。箱庭の畏れは、灯籠ではない道しるべの灯りと朱い月の、静かな夜の不気味さまで（06 §2.3）。驚かせる演出はせず、【創作】くらがり「こわがらなくていい。話すだけだ」のように、やさしさで閉じる。

### 5.2 神仏・宗教・繊細な題材
| 題材 | ルール |
|---|---|
| 神仏 | 今も祀られている神仏（立山権現・刀尾権現・阿弥陀如来・不動明王・姥尊など）はキャラクターにせず、姿を描かず、代弁しない。妖怪は「あのお方」「山の神さま」と呼ぶ。絵では光・雲・山の形 |
| 雷鳥 | 「立山の神さまの使い」に固定し、「山の神さま」「あのお方」と結びつけない。「雷鳥は立山権現の使い」とは書かない。護符の効き目は語らない |
| 縁起 | ましろを開山の白鷹として話させない。地名の由来話は札にしない（明治以降の書き直しがある #1） |
| 女人禁制・布橋灌頂会・姥尊 | 良いことのように描かず、今も続く儀礼を批判もしない。姥尊は姿を見せない。道順をなぞらせず、目隠しを真似させない。奪衣婆の面は怖く描きすぎない（#6）。お糸の姿と贈り物（白い糸）は、糸・布・衣を思わせない案（絵筆の毛、墨）も用意して当事者に確認する。札は監修と当事者（布橋灌頂会実行委員会・芦峅女性の会・雄山神社）の了承まで公開しない。布橋のまわりは、了承が出るまで箱庭にも入れない |
| 地獄（#3） | 茶化さない。亡くなった人を集める対象にせず、第三章と切り離す |
| 疫病（#9） | 「告げたとされる」話にとどめる。共有を疫病よけに重ねない。薬の効き目や予言との因果は語らない |
| クタベ | 姿を作らない・描かない。協業が決まるまで文字と薬草の景色だけ |
| 確度 | 伝承の事実は 03 の内容だけを使い、使うのは「確認済」だけ。03 の §3（知識の連鎖）・§4（暦）は確度ラベルがないので、Claude が11月中に 03 へラベルを付け足すまで「要確認」として札にしない（公的な出典なので確認済になる見込み）。§5 は使わない。閻魔堂の像の指定区分は語らない。#13 は使わない。「刀尾権現と刀尾天神剱岳神は同じか」は監修まで言い切らない |
| 見た目・施設・読み | 護符・御朱印に似せない（旅印も同じ。§3.11）。社寺名や由緒は了承前は画面にもデータにも出さず「この地点」と書く。**社名を外しても、由緒の中身（三社の構成と祭神 #2、開山の縁起 #1 など、神社が「御由緒」として載せている話）は由緒として扱い、札は「了承待ち」にする**（02 F-71）。神仏名・地名・人名のふりがな一覧を作り監修に回す |
| 3Dの箱庭 | 境内は「お休みの範囲」の霧で、中に入れない。社殿・鳥居・宿坊・個人宅を作り込まない（名前のない一般的な家並みならよい）。仮の家並みも実在の家を写さない。灯りは社寺の灯籠ではなく、道しるべの小さな行灯（06 §3.9） |

### 5.3 安全と自然保護を「世界のルール」で伝える
| 決まり | 世界の中での言い方 |
|---|---|
| 歩きスマホをさせない | 妖怪は、立ち止まった人にしか見えない（家では、耳を澄ました人にしか見えない） |
| 移動中は操作させない（F-61） | 道中は、ましろが眠っている |
| 境内では使わせない | 【創作】「ここから先は、祈りの場所。妖怪は外で待っている」。箱庭でも境内は霧で、中に入れない |
| 夜に外へ出させない（F-62） | 夜は気配だけ。話は家や宿の夜話で聞く |
| 暗くなる前に帰す | 麓では逢魔が時に妖怪たちも帰っていく。「駅まで ○分」 |
| ライチョウを追わせない（F-63） | 雷鳥自身が「近づかないで、そっと見守って」と言う |
| 山に入らせない | 山の章は霧の中 |

- 夢の旅は家で遊ぶので、上の制限（歩きスマホ・道中）はかけない。ただし、現地へ誘う言葉は上の決まりと同じにする（夜に出かけさせない、立入禁止の場所やライチョウに近づかせない）。
