## 1. ゲームへの示唆（まとめ）

1. **プレイヤーの役割は「現代の絵解き師（見習い）」にする案。** 江戸時代、芦峅寺の衆徒は立山曼荼羅を携えて全国の檀那場を廻り、絵解きをして護符や反魂丹を配った。つまり立山には、物語を集めて人に語り広める役割がもともとあった。プレイヤーが伝承を集めて「自分の曼荼羅」を完成させ、人に語る（共有する）ことを、そのままゲームの目的にできる。
2. **雷鳥から始める知識の連鎖は、ほぼ成り立つ。ただし1か所だけ根拠がない**（§3-A）。「雷鳥＝立山信仰の神の使い」「立山の神＝立山大権現雄山神（伊邪那岐神）、本地は阿弥陀如来」はそれぞれ確認できた。ところが「雷鳥は立山権現の使い」と直接書いた公的資料は見つからなかった。ゲームでは「立山の神さまの使い」と表現し、二つの事実はつなげずに別々に見せる。**LLM に伝承の作り話をさせないルールが必要な理由**の、ちょうどいい実例になった。
3. **女人禁制をめぐる伝承**（布橋灌頂会・姥尊・止宇呂尼）は、「女性の視点から語り直す」という、大人向けの物語の柱になりうる。ただし、女人禁制そのものを肯定的に描かないこと。
4. **薬・海・山がつながる。** クタベ（立山に住むとされた予言獣。話が広まったのは江戸などの都市で、立山の地元の伝承ではない）→ 幕府による薬草調査 → 衆徒が配った反魂丹 → 富山の売薬 → 昆布と北前船。名産品を、無理に結びつけずに物語の中に置ける。
5. **MVP の舞台「麓」（岩峅寺・芦峅寺）だけでも、主要な題材がそろう。** 開山伝説・雄山神社・立山曼荼羅・布橋灌頂会・姥尊・天狗の光蔵坊・クタベ（立山博物館の研究と展示として。麓の地元で語られた話ではない）・反魂丹。

## 3. 知識の連鎖（プレイヤーが段階的に開いていく例）

### A. 雷鳥 → 立山の神 → 阿弥陀如来（1か所だけ根拠がない）
1. 雷鳥は立山信仰で「神の使い」とされ、雷や火から守ると信じられた［観光庁DB／とやま観光推進機構］
2. 江戸時代に「立山雷鳥」と刷った護符が実在した［県立図書館］。衆徒は護符を携えて全国を廻った［立山博物館］
3. 立山の神は、立山大権現雄山神（伊邪那岐神）［雄山神社］
   - ⚠ 「雷鳥は立山権現の使い」と直接書いた公的資料・一次資料は見つかっていない。ゲームでは「立山の神さまの使い」と表現し、ステップ1と3はつなげずに別々の事実として見せる。
4. 立山権現の本地は阿弥陀如来［雄山神社］。江戸時代の「立山本地阿弥陀如来護符」も残っている［県立図書館］
5. 開山伝説の熊は、有頼の矢が胸に刺さった阿弥陀如来だった［立山博物館］
6. 明治の神仏分離で、芦峅寺（中宮寺）は雄山神社の中宮祈願殿になり、姥堂は取り壊された［雄山神社／細木2018］

### B. 蜃気楼 → 喜見城 → 帝釈天 → 立山
1. 魚津の蜃気楼は、1669年の『寛文東行記』が国内で最も古い確かな記録［魚津埋没林博物館］
2. 前田綱紀が「喜見城」と名付けたと伝わる［同館／文化遺産オンライン］
3. 「蜃」は気を吐いて楼閣を見せる大きなハマグリ、または竜［同館］
4. 喜見城とは、須弥山の頂にある帝釈天の城のことで、蜃気楼の別名でもある［[コトバンク](https://kotobank.jp/word/喜見城)］
5. 立山の別山の山頂にも、帝釈天像（重要文化財、立山博物館所蔵）が安置されていたとみられる［立山博物館］

### C. 薬草 → クタベ → 衆徒 → 富山の売薬
1. クタベは、立山で薬草採りの前に現れて疫病を予言したとされる。ただし、この話は江戸などの都市で刷物として広まったもので、立山の地元では語られていない［立山博物館］
2. 1722年、幕府の採薬使が立山・黒部の奥山で薬草を調べた［[吉野1999紀要](https://tatehaku.jp/wp-content/themes/tatehaku/common/images/pdf/bulletin/1999/06_1999_02.pdf)］
3. 芦峅寺の衆徒は、江戸の檀那場で反魂丹も配っていた［福江1999紀要］
4. その先に、行商の道具が重要有形民俗文化財になった、富山の売薬がある［文化遺産オンライン］

## 5. 確認できなかった点・出典どうしの食い違い

- **雷鳥:**
  - 「立山権現の使い」はブログにしか出てこない。
  - 護符の効能（雷除け・火除け）は観光庁DBの説明だけで、図書館の目録には書かれていない。
- **開山の年と開山者:** 縁起では701年だが、父の有若が実在したと確認できるのは905年の文書で、年代が合わない。古い文献では、開山したのは有若や狩人とされている。
- **熊と鷹の割り当て:** 「熊＝阿弥陀如来、鷹＝不動明王」は観光向けの説明。雄山神社は「鷹にも熊にもなった」と、両権現のお告げとして語っている。
- **閻魔堂の像の指定区分:** 「重要文化財」とする資料と「県指定」とする資料がある。
- **早百合・黒百合:** 後の時代につくられた物語で、黒百合伝説は年代が矛盾している。
- **ます寿司の起源:** 献上した人物の名前が、出典によって違う。
- **おわらが1702年に始まったという説:** 一つの説にすぎない。
- **剱岳の錫杖頭が見つかった経緯:** 1907年に測量隊が見つけたとされるが、公的資料では確かめていない。
