# 妖怪ARゲーム コンセプトブリーフ v0.1（たたき台）

> 位置づけ: 最初の議論用ドラフト。決定事項ではなく「仮説＋問い」の集まり。
> 作成日: 2026-10-16

## 1. 一行コンセプト（仮）

**「土地の妖怪の悩みを聞き、ほどくことで、その土地の文化と神話を知っていく、位置情報×AR のコミュニケーションRPG」**

- 遊びの核は「戦って捕まえる」ではなく「話して、仲良くなって、関係をほどく」
- 学びはご褒美として後から付いてくる（教材っぽくしない）
- 日本から始め、同じ枠組みで世界の民間伝承（精霊・妖精・ジン等）に拡張

## 2. 参考作品の比較

| 作品 | 核の遊び | 取り入れたい点 | 避けたい点 |
|---|---|---|---|
| 妖怪ウォッチ（Level-5, 2013〜） | 日常の「困りごと」を妖怪のせいにする→妖怪と友達になりメダル収集・バトル | 「悩み＝妖怪の仕業」という発想、友達になる収集 | ギャグ・キャラ化が強く伝承から離れる。子供向けに寄りすぎ |
| 妖怪ウォッチ ワールド（GPS版, 終了済） | 位置情報で妖怪を探す | 「地域限定妖怪」の仕組み | 実在の伝承と結びつかず、本家の縮小版になった |
| ポケモンGO | 歩く→出会う→捕まえる、ジム/レイド | 散歩の習慣化、ローカル名所の活用、ソーシャル | 収集が作業化。土地の意味は薄い |
| どうぶつの森 | 住民との会話・関係づくり・季節イベント | 「毎日ちょっと話したくなる」関係性、ゆるさ | 物語の起伏が少ない |
| 大神（カプコン） | 日本神話×筆しらべ、浮世絵調 | **和の美術表現の最良の手本**、神と動物の使いの世界観 | — |
| 蟲師 / もののけ姫 / 夏目友人帳 | 人と妖が「すれ違い→理解」 | トーン（静けさ・畏れ・やさしさ） | — |

**ポジショニング仮説:** 妖怪ウォッチ（ポップ・ギャグ）と蟲師（静か・大人）の間。
「ポケモンの親しみやすさ × 大神の和の美術 × 夏目友人帳の情緒」。

## 3. コアループ（仮）

```
歩く（GPS） → 気配を感じる（地図に揺らぎ） → ARで姿を見る
  → 話す（LLM会話＋固定シナリオ） → 悩み・いざこざを知る
  → 解決（調べる／ものを届ける／他の妖怪をとりもつ／ときに"鎮め"の勝負）
  → 縁（なかま）と旅の記録（曼荼羅帳・旅印）＋伝承の一節が開く ※御朱印には似せない（[05](05-overview-and-roadmap.md) §3）
  → 土地の「縁起絵巻」が埋まっていく
```

### 配置の考え方（ハイブリッド）
1. **主（ぬし）/ 物語妖怪** — 実在の伝承地（神社・川・峠など）に固定。地域ストーリーの中心。
   例: 立山の雷鳥＝山の神の使い、という話を辿ると立山信仰・神の正体に行き着く
2. **土着の妖怪** — 地域ごとの出現テーブルで自動配置（河童は水辺、天狗は山…）
3. **季節・祭り妖怪** — 実際の祭礼・暦（節分、お盆、百鬼夜行）と連動したイベント

### バトルは要るか？ → 「鎮め（しずめ）」という代替案
殴り合いではなく、和の遊びをモチーフにした短いミニゲーム
（例: 謎かけ・言葉合わせ・囃子のリズム・札合わせ）で「荒ぶった妖怪を鎮める」。
ゲーム的な緊張感は残しつつ、世界観と矛盾しない。

### 収集の層（名産品とのバランス）
| 層 | 例 | 役割 |
|---|---|---|
| 縁（妖怪） | 友達になった妖怪 | メインの収集・図鑑 |
| 伝承の一節 | 絵巻・由来 | 学びの収集（読み物） |
| 供物・道具 | 地域の名産品を「妖怪が欲しがるもの」として登場 | ゲーム内アイテム。**名産品はあくまで妖怪の好物という文脈で出す** |
| リアル連携（後） | 店舗・自治体の実物クーポン等 | 収益/地域連携。ゲーム性の核からは切り離す |

→ 名産品は「主役」にせず「妖怪との関係をつなぐ道具」に置くことで、ゲーム性と地域性を両立させる。

## 4. 技術リサーチ（2026年10月時点）

### 4.1 AR / 位置情報

> **更新（2026-10-16）:** Claude Code でバイブコーディングする前提を踏まえ、three.js（Web）を先に使う方針を提案した。詳細は [01-tech-stack-decision.md](01-tech-stack-decision.md)。下の表は初回リサーチ時点のもの。

| 候補 | 状況 | 評価 |
|---|---|---|
| **Unity + AR Foundation**（ARKit/ARCore） | 安定。iOS/Android両対応 | **本命の土台** |
| **ARCore Geospatial API**（Google, Street Viewベース VPS） | 日本の都市部はカバー良好。iOSも可 | 「この鳥居の上に妖怪」を実現する本命 |
| Niantic Spatial SDK（旧 Lightship ARDK） | ARDK 3.x は 3.17 で最終、3.x は 2027/2/28 まで。Shared AR は 2026/5/1 で停止。4.x へ移行必須。lightship.dev は閉鎖し scaniverse.nianticspatial.com に移行 | 機能は強いが**プラットフォームの変動が大きい**。依存は最小限に |
| 8th Wall（WebAR） | 2026/2/28 で編集終了、ホスティングは 2027/2/28 まで。エンジンの主要部はオープンソース化（8thwall.org） | ブラウザ体験版には使えるが本体には不向き |
| WebXR + three.js | PC/スマホブラウザで動く | PC版・プロモ用の軽量版に良い |
| 地図 | Mapbox / Google Maps SDK / OSM | 和風スタイルの地図を描くなら Mapbox か OSM＋自前スタイル |

### 4.2 ARグラス（2026年10月時点）
| 候補 | 状況 | Unity |
|---|---|---|
| Android XR グラス（Google） | SDK は Developer Preview 4、グラス系ライブラリは alpha | 未確定 |
| Snap Specs | 秋発売予定（約$2,195〜2,500）。Lens Studio（JS/TS）のみ | **非対応** |
| Meta（Ray-Ban Display 等） | Wearables Device Access Toolkit 1.0 公開、ストア公開経路はまだ | 未確認 |

**方針案:** グラスは「今は勝負しない、でも塞がない」。
ゲームロジック・データ・会話サーバをクライアントから分離し、グラス版は
「音声で妖怪と話す＋簡易表示」の別クライアントとして後から足せる設計にする。
（グラスは現状、高精細3D表示よりも音声・通知が得意 → 会話中心の本作と相性が良い）

### 4.3 LLM（妖怪との会話）
- **Gemma 4**（2026/4 リリース, Apache 2.0）: E2B/E4B は端末内オフライン動作可、日本語含む多言語・関数呼び出し対応。
  ただし E2B でも RAM 8GB 目安 → 対応端末が限られる
- **推奨: ハイブリッド構成**
  - 物語の重要会話・伝承の事実 → **人が書いた固定シナリオ**（誤情報を防ぐ）
  - 雑談・反応・口調 → LLM（クラウド既定、対応端末ではオンデバイス Gemma 4 を選択可）
  - LLM には「キャラ設定＋その妖怪が知ってよい伝承テキスト」だけを与える（RAG）。
    伝承の創作・捏造を禁止するガードレール必須
- 子供が遊ぶ可能性がある以上、会話の安全フィルタは必須要件

### 4.4 伝承データの出典候補
- 国際日本文化研究センター「怪異・妖怪伝承データベース」
- 各自治体・郷土資料館の資料、地域の語り部
- 神社・寺の由緒（掲載は要許諾。宗教施設の扱いは慎重に）

## 5. 早めに潰すべきリスク
1. **安全・迷惑**: 私有地・神社境内・夜間への誘導、歩きスマホ。配置ポイントの審査と除外リストが必須
2. **文化・宗教への配慮**: 神様をキャラ化する際の線引き。監修者（民俗学者）の確保
3. **LLMの誤情報**: 「文化を学べる」と言う以上、事実は固定テキスト側に置く
4. **プラットフォーム変動**: Niantic/8th Wall の例のとおり。特定ベンダー依存を避ける
5. **コンテンツ量**: 位置情報ゲームは地域が空っぽだと即死。最初は1地域に絞って密度を出す

## 6. 開発ステップ案
1. **コンセプト確定**（今ここ）: ターゲット・トーン・コアループ
2. **イメージボード**: 画風3案（浮世絵/墨絵調・絵本調・ポケモン寄りデフォルメ）を作り比較
3. **パイロット地域を1つ決定**し、妖怪10〜20体・主ストーリー1本を設計
4. **プロトタイプ**: three.js（Web）で「歩く→出会う→話す」だけを作る（技術選定は [01-tech-stack-decision.md](01-tech-stack-decision.md)）
5. 遊んでもらい検証 → バーティカルスライス → 地域拡大 → グラス対応

- [x] **メインターゲット**: 20〜40代の「和もの好き」の大人
