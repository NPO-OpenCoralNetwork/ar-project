## 0. 当日の使い方（30秒で読む）

1. 地点に着いたら、**§6 の「地点ごとの確認」を上から順に**見る。
2. メモは §8.4 の書式を、iPhone の「メモ」にコピーして埋める。
3. 迷ったら、**記録だけして判断はあとで**。Claude が写真・メモから整理します。
4. 安全が先。暗くなる前に駅へ。林の中は早く暗くなります。

**地点 ID の付け方**（メモ・写真・録音で同じ ID を使う）

| ID | 意味 |
|---|---|
| I-1〜I-4 | 岩峅寺の、今の候補地点（データの iwakuraji-1〜4） |
| I-c1〜 | 岩峅寺の、調べる地点（データの iwakuraji-c1〜） |
| I-5〜 | 岩峅寺で、現地で見つけた新しい候補 |
| A-1〜 | 芦峅寺の候補 |
| IY-1〜／AY-1〜 | 予備地点（岩峅寺／芦峅寺） |
| KI-1〜／KA-1〜 | 境内の境目の点（岩峅寺／芦峅寺）。外の公道から記録 |
| SI／SC | 岩峅寺駅／千垣駅 |
| T-1〜 | 将来タグ（NFC）を置けそうな場所 |

メモには**社寺の名前を書かなくて大丈夫**です（「境内（岩）」「境内（芦）」で足ります）。データに名前が混ざらないようにするためです。

## 1. 目的

雪が降る前に、麓（岩峅寺・芦峅寺）を自分の足で確かめ、次の2つの地域パックに入れる材料を集める。

| 使う段階 | 下見の結果で決めること |
|---|---|
| 段階3 現の旅（11月後半に作る。12月のテストは地元の「仮の里・仮の麓」のパックなので、麓のデータは使わない。04 §6.2・05 §6） | 判断の材料として使うのは、**GPS がどのくらい合うか**と**電波**の結果だけ（GPS の設定や判定の半径の目安） |
| 段階3〜4（麓の地域パックの下地） | 地点と予備地点の座標、お休みの範囲（境内）の境目 |
| 段階5 麓の作り込み（1〜2月） | 第一章〜終章の地点、箱庭の家並み・道の様子、環境音、日の入りごろの明るさ、山の見える地点、雪の日の代わりの道 |

あわせて、3月の現地テスト（10〜20人）の段取り（駅からの時間、トイレ、帰りの便）を確かめる。

## 6. 地点ごとの確認項目

ここが本体です。候補地点（I-*, A-*）では §6.1 を全部、予備地点・境目の点などでは関係する所だけ見ます。

### 6.1 候補地点で見ること（1か所 10〜15分）

**着いたらすぐ**
- [ ] GPS の検証ページで「いま止まった」を押す（§8.5）
- [ ] コンパスのアプリの画面をスクリーンショット（**座標と方角が一度に残る**）
- [ ] ID のカードを写真に1枚

**その場に2分立って**（04 §3.1「2分立ち止まっても邪魔にならないか」）
- [ ] 2分のあいだに通った**車の台数・人の数**を数える
- [ ] **邪魔にならないか**: ならない ／ 少し気になる ／ なる
- [ ] **公道か**: 公道 ／ 私道・敷地内に見える ／ 分からない（堤防の上の道は、管理用の道で車両通行止めのことがある。看板を写す）
- [ ] **歩道**: 歩道あり（幅 約○m）／ 白線の路側帯だけ ／ なし。**歩道のない車道には置けない**（04 §3.1）。なければ、すぐ横に**広場・公園・公共の空き地**があるか
- [ ] **前の建物**: なし ／ 住宅 ／ 宿坊 ／ 店 ／ 公共の建物。**住宅・宿坊の前は不可**（向かいや斜め前でも、ずっと見える位置なら「前」と書く）
- [ ] **境内までの距離**（目で。50m 以上ほしい。04 §3.1）
- [ ] **河原ではないか**（河原には置かない）
- [ ] 出会いの範囲は半径 30〜50m なので、**まわり 50m に危ない所**（交差点、段差、水路のふち、踏切）がないか
- [ ] 地点の画面の**精度**の数字をメモ（§8.5）

**写真と音**（§8.2・§8.3）
- [ ] 道の両方向・その地点の背景・足元（歩道の様子）
- [ ] 山の方角（§6.4）
- [ ] 環境音 30秒

**その他**
- [ ] **電波**: キャリア名、アンテナの本数、検証ページや地図がすぐ読み込めるか（§6.6）
- [ ] **雪の日**: 使えそうか（◎ ／ ○ ／ ×）。§6.7
- [ ] 近くの**トイレ**・屋根・自販機
- [ ] 駅（バス停）からここまで**歩いた分数**
- [ ] ひとこと（雰囲気、音、気づいたこと）
- [ ] GPS の検証ページで「歩き始めた」を押してから歩く

### 6.2 予備地点（IY-*／AY-*）

04 §3.10: 雪・荒天・工事・行事の日や GPS が合わない日の代わりに、**各節に1つずつ**。駅や屋根のある公共の場所がよい。

- [ ] 一年中・雪の日でも行けるか（屋根、除雪される道沿い）
- [ ] 駅・バス停から近いか（分数）
- [ ] 公共の場所か（駅の待合、公共施設の外の屋根の下など）。**店・施設の中なら、了承が要る**と書く
- [ ] 2分立っても邪魔にならないか、人の流れ
- [ ] 座標・写真・電波
- 目標: 岩峅寺で 2か所（第一章の2節）、芦峅寺で 4か所（第二章2・第三章1・終章1。04 §3.10 の「各節に1つずつ」。同じ場所を兼ねてよい）。

### 6.3 日の入りごろの明るさ（1か所を定点で）

04 §3.9: 麓では日の入りの1時間前から「駅まで ○分」を出し、逢魔が時に出会いを止める。

- [ ] 同じ場所・同じ向きで、**日の入りの 60分前、30分前、日の入り、20分後**に写真を1枚ずつ（4枚）
- [ ] それぞれで: 足元が見えるか、画面が読みやすいか、街灯は何本・いつ点いたか、心細さ（1〜5）
- [ ] その時刻に**駅まで歩くと何分**か、帰り道に暗い所がないか
- [ ] 夕方の環境音 30秒（逢魔が時の音の素材）
- [ ] 林の中の道（該当する地点）は、何時ごろ暗くなるかだけ遠目に見る（入らない）
- 案A なら芦峅寺、案B なら岩峅寺で。写真は 06 の「夕」の色づくりの参考にも使います。

### 6.4 山の見える地点

終章は「山の方角が見える公開された場所」（04 §4.2）。ちぐさの悩み（付録A #15）も芦峅寺の山の見える地点。

- [ ] 立山連峰が見えるか: 見える ／ 一部 ／ 見えない ／ 雲で不明
- [ ] 方角の目安（岩峅寺から。データの稜線より）: **剱岳 約86°、雄山 約98°、薬師岳 約127°**。手前の前山が 約117° に高く見える。芦峅寺では向きが変わるので、コンパスで測って書く
- [ ] 山に向けた写真（コンパスのスクリーンショットも）
- [ ] 公道・公共の場所から見えるか、立ち止まっても邪魔にならないか
- 雲で見えない日は「見えない（雲）」と書いて、方角だけ記録。

### 6.5 将来タグ（NFC）を置けそうな場所（T-*）

05 §3.2: MVP は GPS だけ。NFC タグは**3月のテストのあとに検討**し、置くのは**了承を得た協力先（博物館・案内所・駅など）だけ**。境内には置かない。**当日は場所を見るだけで、頼んだり貼ったりはしない。**

- [ ] 場所の種類（駅、博物館の屋外、案内所など）と、了承を取る相手（施設の持ち主）
- [ ] 貼れる面（案内板・柱など）、屋根、雨や雪がかかるか
- [ ] 人目があるか（盗まれたり壊されたりしにくいか）
- [ ] 電波（タグは URL を開くので、ネットにつながる必要がある）
- [ ] 写真（場所が分かる程度。掲示物の中身は写さなくてよい）

### 6.6 電波（キャリアごと）

- [ ] 自分の回線のキャリア名を最初に書く
- [ ] 地点ごとに: アンテナの本数、4G/5G の表示、検証ページや地図が**10秒以内**に開けるか
- [ ] つながらない所があれば、その場所の ID を書く（04 §3.10 の「先に読み込む」の要否を決める）
- 2台目がなければ、他のキャリアは「未確認」で構いません。各社のエリアマップは Claude があとで調べます。

### 6.7 雪の道（雪の前に見て分かること）

3月のテストで雪が残っていたときの道を決める材料です（04 §6.5「雪の版」）。

- [ ] 道の真ん中に**消雪パイプ**（水の出る小さな穴）があるか
- [ ] 歩道が除雪されそうか、雪を寄せる場所になっていないか
- [ ] **坂・階段・日陰**（岩峅寺は段丘の縁で、境内から南西の川へ高さ 10m 以上下がる）
- [ ] 雪の日に使えそうか（◎ ／ ○ ／ ×）と、その理由
- 除雪する道の計画は、あとで町に聞く（PO）。

- [ ] 岩峅寺駅（別棟の水洗トイレがあるという訪問記がある。要確認）
- [ ] 立山博物館（開館日・時間内だけ。要確認）

## 8. 記録のしかた

### 8.1 地点ごとの順番（目安）

1. GPS の検証ページで「いま止まった」
2. コンパスのスクリーンショット → ID カードの写真
3. 2分立って、§6.1 を見ながら数える・見る
4. 検証ページの画面をスクリーンショット（精度が残る）
5. 写真 → 録音 → メモ
6. 検証ページに戻って「歩き始めた」→ 歩く

写真や録音のあいだは検証ページが裏に回り、記録に「空白」が出ますが、止まっている間なので構いません。

### 8.2 写真

- **1枚目は ID カード**（その後の写真がどの地点か分かる）
- 道の両方向、地点の背景、足元（歩道・路側帯）、山の方角、境目の線
- 位置と方角は写真に自動で残ります（§5 の設定）。念のため、方角はコンパスのスクリーンショットでも残す
- 横向き・広めに。人が写りそうなときは、通り過ぎるのを待つ
- 渡すときは**元の写真のまま**（LINE などは位置が消えます。共有の「オプション」で「位置情報」をオンに）

### 8.3 環境音の録音

- iPhone の「ボイスメモ」で **30秒ずつ**。録る間は話さず、動かない
- ファイル名を **「ID 時刻 昼/夕」**（例: `I-2 1032 昼`）に変える
- 録りたい音の例: 川（堤防の上から）、用水、林の風、集落の静けさ、踏切と電車、鳥、夕方の音
- 人の話し声が入ったら録り直すか、メモに「声あり」と書く（あとで使わない）
- 風が強い日は、風の音だけになりやすい。体で風をさえぎって録る

### 8.4 メモの書式（コピーして使う）

```
ID: I-1
時刻: 11/14 10:32
座標: 36.60819, 137.31609（精度 8m）
種類: 候補 / 予備 / 境目 / 山 / タグ
公道: はい / いいえ / 不明
歩道: あり（幅 約1.5m）/ 路側帯だけ / なし
2分: 車 3台・人 1人 → 邪魔にならない / 少し / なる
前の建物: なし / 住宅 / 宿坊 / 店 / 公共
境内まで: 約 90m
まわり50m の危ない所:
山: 見える（約98°）/ 一部 / 見えない / 雲
電波: (キャリア) 4本 5G、10秒以内に開いた
雪の日: ◎ / ○ / ×（理由）
トイレ・屋根:
駅から: 歩いて 7分
写真: IMG_1234〜1241
音: I-1 1032 昼
ひとこと:
```

座標はコンパスのスクリーンショットから写すか、空けておいてください（写真の位置から Claude が読み取ります）。

### 8.5 GPS の精度（段階0.5 の検証ページを使う）

- 歩き出す前に、公開先の `gps-test.html` を開いて「はじめる」。電池残量を入れる
- **各地点に着いたら「いま止まった」、出るときに「歩き始めた」**。地点で2分立つことが、そのまま「止まった判定」の確認になります
- 地点ごとに、画面の **精度（m）** をメモ
- 記録は端末の中に**2回分しか残らない**ので、**岩峅寺が終わったら一度「終える」→ コピー**して「メモ」に貼り、芦峅寺で新しく始める
- 書き出しの「**緯度経度も含める**」は、下見では**オンを推奨**（地点の座標と合わせるため。自宅の位置は入りません。PO が決める）
- メモ欄に、天気・ポケットの場所・林や段丘の様子を書く
- 特に見たい所: 境内の境目のそば（GPS のずれで出入りしないか）、林の中、段丘の下

## 9. 撮影・録音で配慮すること

- **参拝者・住民を写さない・録らない**。顔だけでなく、表札・車のナンバー・洗濯物・家の中が見える窓も避ける
- **境内では、掲示された撮影のルールに従う**。本作のための写真・録音は**境内の外の公道から**撮る。境内に入るのは、ふつうの参拝として
- 境内の音（鐘、祈りの声など）は録らない
- 宿坊・個人の家の前で長く立ち止まらない。敷地に入らない
- 個人の所蔵品（04 §3.1 の「天狗様」）や、祀られている神仏を、本作のために撮らない
- 行事の日は、行事の場所に近づかない
- 三脚やドローンは使わない
- 写真・音は**参考に使う**もので、そのままゲームに入れません。リポジトリは公開設定なので、写真・音の元のファイルは**リポジトリに入れない**（置き場所は §11）

**声をかけられたときの一言（例）**
「地域の歴史を紹介する散歩ゲームを作っていて、歩きやすい道を見て回っています。人や家は写していません。」

## 12. PO が決めること

1. **下見の日程**（11月中旬の平日か土曜。案A の1日か、案B の2日か。おすすめは案B）
2. **雄山神社への相談を、下見の前にするか後にするか**（08 §0.1・§5 #2 と同じ問い）。案(a) 博物館と同時に10月末〜11/2 に送る（前なら境目と撮影の考え方を当日に生かせる）／案(b) 下見の後の11月下旬に送り、下見では境内の外の公道からの記録だけにする。提案は案(b)
3. **GPS の検証の書き出しに緯度経度を含めるか**（下見ではオンを推奨）
4. **写真・音の置き場所**（公開のリポジトリの外。チャットへの添付か、共有フォルダか）
5. 2台目の回線を用意するか（他のキャリアの電波を比べるなら）
6. 下見の交通費（05 §7 のお金の上限に含める）
7. 駅名を画面に出すか（地名の札の扱い。04 §5.2・§7）。**社寺名を含む駅名・バス停名（大川寺、芦峅寺線の「雄山神社前」など）は、了承前は出さない。** 岩峅寺・芦峅寺・千垣のような地名の駅だけ出すかを決める（「駅まで ○分」の表示に関わる）

**この一覧で確かめていないこと**: 電車の時刻・本数（地鉄の公式ページで要確認）、岩峅寺駅のトイレ、近くの店、立山博物館の開館日、地鉄・町営バスで交通系IC が使えるか、町の除雪の計画。
