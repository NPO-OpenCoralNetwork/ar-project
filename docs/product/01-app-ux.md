# アプリの画面と使い心地 v0.1

> 作成日: 2026-10-17 ／ ステータス: **案。[00 プロダクトの全体像](00-vision.md) の PO 確認と一緒に見てもらう**
> 対象: プレイヤーが遊ぶ Web のゲーム（PC とスマホのブラウザ）と、パートナー向けの管理の道具の概要。
> もとにした文書: [04 ゲームデザイン v0.2](../yokai-game/04-game-design-v0.1.md)（§2.1 序の口、§3 システム、§5 トーンと表現のルール）、[05 全体整理](../yokai-game/05-overview-and-roadmap.md)（§3 二つの旅）、[06 光と霞](../yokai-game/06-art-direction.md)、[02 MVP 要件 v0.2](../yokai-game/02-mvp-requirements.md)。
> 表記: 【創作】＝本作の作り話。「（例）」は説明のための見本で、実在の店・人数ではない。画面の名前はすべて仮。

---

## 0. 画面づくりの考え方（5つ）

1. **入口は「土地を選ぶ」こと。** 開くと絵地図があり、土地を選んで入る。ゲームのメニューより、旅の支度をしている感じにする。お店の棚やポータルに見せない。
2. **遊んでいる間の画面は静かに。** 箱庭や地図の上には、遊びに要るものだけを置く。協賛・お知らせ・数字を遊びの途中に出さない。
3. **どの画面でも、いま自分が「家（夢）」と「現地（現）」のどちらにいるかが分かる。** 夢は白描と金色の霞、現は色。
4. **安全とお休みは「世界の言葉」で伝え、普通の言葉でも添える**（04 §5.3）。
5. **見本（例）と本物を混ぜない。** 見本の店名・数・灯りには、画面の上でも「例」と書く。

## 1. 情報設計

### 1.1 画面の階層

```
起動・タイトル
 ├─ 初回だけ: 序の口（三つの約束 → どちらの旅で始めるか）
 └─ 旅（タブ）
     └─ 絵地図（土地を選ぶ）
         └─ 土地の入口（カード）
             ├─ 夢の旅: 箱庭 ──┬─ 出会い（夢の姿）→ 会話 → 札・ピース → 灯りを置く
             │                 ├─ 休み処の札
             │                 ├─ 灯り・置き手紙を読む
             │                 └─ （宵の集い。後の段階）
             └─ 現の旅: 地図 ──┬─ 出会い（色の姿・AR 段階0/1）→ 会話 → 旅印
                               ├─ 休み処に立ち寄る → 供物
                               ├─ お休みの範囲（止まる）
                               └─ 道中（ましろが眠る）
 ├─ 帳（タブ）: 帳の表紙 → 土地ごとの頁（立山は曼荼羅帳）→ 巻末の旅印 ／ 縁帳（妖怪ごと）／ 伝承の札
 ├─ 便り（タブ）: 古笠の便り、夜話、祭りの知らせ、噂の地
 └─ 支度（タブ）: 引き継ぎ、音・文字の大きさ・見た目、二つの旅のルール、土地と祈りへの配慮、出典とクレジット、運営について
重ねて出るもの: 祭りの終わりの「お礼の札」、休み処の札、確かめの小窓（位置の許可など）
```

## 2. 主要な流れ

### 2.1 初めて開く → 土地を選ぶ → 入る → 遊ぶ → 帳 → 戻る（家）

| # | プレイヤーがすること | 画面 | 画面が返すこと |
|---|---|---|---|
| 1 | URL を開く | A1 | 金色の霞、ましろが横切る。会員登録はない。「旅をはじめる」 |
| 2 | 「旅をはじめる」 | A2 | 真っ白な帳が開き、紙からましろが生まれる【創作】。三つの約束を1画面ずつ（飛ばせない）。文字の大きさを選ぶ |
| 3 | 「夢の旅（家で）」を選ぶ | A2 | 位置もカメラも使わないので、許可は頼まない |
| 4 | 立山のピンを押す | B1 → B2 | 土地の入口のカードが下からせり上がる。「夢の旅で入る」が大きく明るい |
| 5 | 「夢の旅で入る」 | C1 | 霞が晴れて箱庭（昼）。ましろ【創作】「ここは夢の中の麓。耳を澄ますと、誰かいる」 |
| 6 | 歩いて墨のにじみに近づき、「耳を澄ます」を押し続ける | C1 → C2 | 数秒で白描の妖怪が浮かぶ。台本の会話。悩みごとが始まる |
| 7 | 悩みをほどく | C2 | 伝承の札が開く（出典つき）→ 帳にピースが入る演出 → 縁が上がる |
| 8 | （3月の後）灯りを置く | C3 | 近くの道しるべに白い紙の灯りがともる。「明日には、ほかの旅人にも見えます」 |
| 9 | 「帳」を開く | E1 | 立山の頁。白描のピースが増えている。巻末の旅印の枠は空いている |
| 10 | 「戻る」 | C1 → B2 → B1 | 土地の入口 → 絵地図。絵地図の土地の明るさはそのまま（翌日以降に開くと、みんなの灯りの分だけ少し明るくなっている。00 §5.6）。置いた灯りは、箱庭の中の自分の画面でだけ、すぐ見える（C3） |

2回目からは、A1 の「つづきから」で**最後にいた場所**（箱庭か絵地図）に戻る。

### 2.2 現地での流れ

| # | 場面 | 画面 | 画面が返すこと |
|---|---|---|---|
| 1 | 駅で開く。引き継ぎコードを入れる（初回だけ） | G1 | PC の続きが入る |
| 2 | 立山の入口で「現の旅で歩く」 | B2 | 位置の許可を頼む（理由:「気配を出すため。歩いた道は記録しない」） |
| 3 | 画面を開いたままポケットへ | D1 | 歩いている間は地図に動く演出を出さない。気配が近いと小さな鈴の音 |
| 4 | 立ち止まって画面を見る | D1 | 近くの気配がまとめて出る。数秒止まると澄む |
| 5 | 妖怪が現れる | C2（現） | 色のついた姿。【創作】「夢で見た顔だな……本当に来たのか」。曼荼羅のピースに色 |
| 6 | 乗り物で移動 | D3 | 自動で道中の画面。「道中は、ましろが眠っている」 |
| 7 | 境内に近づく | D2 | 【創作】「ここから先は、祈りの場所。妖怪は外で待っている」＋「境内ではゲームを使えません」。出会い・カメラ・会話が止まる |
| 8 | 節を終える | D4 | 帳の巻末に日付入りの旅印（インク1色の絵柄。朱の印と墨書きの組み合わせにしない） |
| 9 | 日の入りが近い | D1 | 【創作】「逢魔が時。妖怪たちも帰っていく」＋「駅まで ○分」 |

### 2.3 休み処（協力先）に寄る流れ

| # | 場面 | 画面 | 中身 |
|---|---|---|---|
| 1 | 家の箱庭で、道沿いの縁台と行灯に気づく | C1 | 看板やロゴはない。物語の地点からは離れた道沿いにだけある |
| 2 | 触れる | C4 | 札が出る:「協力先」の印、店の名前（例）、現地で何がもらえるか（例: 昆布）、営業の時間（協力先が出す情報）、「買い物はしなくてよい」「寄らなくても物語は進みます」 |
| 3 | 現地で地図を開く | D1 | 地図の端に休み処の小さな札（「協力先」の印つき）。気配の札とは形を変える |
| 4 | 店に入る | D1 | 店の前で立ち止まると供物がもらえる。3月の後は GPS だけで確かめる。NFC か QR はその後 |
| 5 | 供物を妖怪に渡す | C2 | 妖怪は「昆布」のような一般の名前で言う。店の名前や商品名は言わない |

公開版では13歳未満には C4 と D1 の休み処を出さない（00 §10 #4）。

### 2.4 ゲームの中の祭りの流れ（後の段階）

| # | 場面 | 画面 | 中身 |
|---|---|---|---|
| 1 | 祭りの始まり | F1 | 古笠の便り「灯り市が始まるそうな」（例）。プッシュ通知は使わない。便りのタブに小さな点だけ |
| 2 | 絵地図を開く | B1 | 立山のピンに祭りの印。土地全体の灯りの進み具合を、光の量で見せる（数字は出さない） |
| 3 | 箱庭で灯りを置く | C3 | いつもより灯りが多い。祭りの間だけの悩みごと |
| 4 | 目標に届く | C1 | 箱庭が「祭りの夜」になり、妖怪たちが集まる特別な会話 |
| 5 | 祭りの終わり | H1 | **お礼の札**: 祭りに関わった妖怪、作り手、協賛の店（例）の名前が、ゆっくり流れる。ここが、遊びの中で協賛の名前が出る唯一の場面 |

実在の祭礼の日は、周辺の地点を「お休み」にし、その日の便りで静かに知らせる。

### 2.5 戻り方
- どの画面からも、左上の「戻る」で一つ上の階層へ。箱庭と地図では「土地の入口」へ戻る。
- ましろをタップすると、小さな輪のメニュー（帳・便り・絵地図へ戻る）が出る。
- 会話の途中は「会話をやめる」でいつでも抜けられ、続きは次に話しかけたときに戻る。

## 3. ナビゲーション

### 3.1 下のタブ（4つ）

| タブ | 中身 | 印 |
|---|---|---|
| **旅** | 絵地図 → 土地の入口 → 箱庭／地図 | 新しい土地や祭りがあると小さな灯り |
| **帳** | 帳（土地ごとの頁）、縁帳、伝承の札 | 新しいピースが入ると小さな点 |
| **便り** | 古笠の便り、夜話、祭り、噂の地 | 届くと小さな点。数字のバッジは出さない |
| **支度** | 設定、ルール、出典、引き継ぎ | ― |

- 箱庭（C1）と地図（D1）の中では、**タブを隠して画面を広く使う**。
- PC では、タブを画面の下ではなく左の細い縦の列に置いてもよい（幅が 900px 以上のとき）。
- ランキング、人気順、他人の数字は、どのタブにも出さない（02 §5.9）。

### 3.2 箱庭の中の操作（HUD）

画面に出す操作は**3つだけ**: **耳を澄ます**（気配の近くでだけ大きく出る）、**帳**、**ましろ**（メニュー）。ほかに、常に出すのは「戻る」と出典表示だけ。

| 位置 | もの | 決まり |
|---|---|---|
| 左上 | 戻る、土地の名前（小さく） | ― |
| 右上 | 帳、ましろ | いまの試作の「回転・速さ・見た目・時間・画質」は、支度の中か、長押しの小さなパネルへ移す |
| 下の中央 | 耳を澄ます | 気配のにじみの中に入ったときだけ現れる。指を置いて数秒 |
| 右下 | 出典表示（© OpenStreetMap contributors／地理院タイル（標高）を加工して作成） | **常に表示**（F-44）。小さく、読める濃さで |
| 移動 | スマホは画面の左下を親指でドラッグ（スティック）、PC は WASD／矢印キー | いまの試作のまま |

### 3.3 地図（現の旅）の中の操作

| 位置 | もの |
|---|---|
| 左上 | 戻る |
| 右上 | 帳、ましろ |
| 下 | 状態の帯（「立ち止まると、気配が澄みます」「道中は、ましろが眠っている」「ここは祈りの場所」）。帯は1行、世界の言葉＋普通の言葉 |
| 右下 | 出典表示 |

AR 段階1（カメラに重ねる）は、出会いのときにだけ「カメラで見る」を出す。常にカメラを開かない。

## 4. 画面ごとの要素と状態

### A1 起動・タイトル
- **要素**: ゲームの名前（仮）、金色の霞の背景（夜に開いたら夜の藍）、ましろ、「旅をはじめる」／「つづきから」、文字の大きさ、出典表示。
- **状態**: 初回／2回目以降／読み込み中（霞が晴れていく動きで見せる。進み具合の数字は出さない）／読み込みに失敗（「霧が深くて進めません。もう一度」＋再試行）。

### A2 序の口
- **要素**: 三つの約束（1画面に1つ、「わかった」）、旅の選び方（夢／現）、位置とカメラの許可の説明。
- **状態**: 位置を断った（夢の旅と帳で遊べる、と伝える）／カメラを断った（AR 段階0 で遊べる）。

### B1 絵地図
- **要素**: 鳥瞰の絵地図（国境は描かない）、土地のピン、ピンのまわりの灯り（量だけ。数字なし）、祭りの印、「噂の地」（霞の中のぼんやりしたピン）。
- **状態**:
  - 入れる土地: 琥珀色に灯る。
  - 噂の地: 霞の中で淡く、押すとましろが「あっちのほうから、まだ聞いたことのない話が聞こえる」【創作】と言うだけ。入れない。日付は出さない。
  - 2巻目が決まるまでは、立山のピンだけ。
  - 時間帯: 昼は金の霞、夜は深い藍に琥珀の灯りと朱い月（立山の時刻に合わせる。立山のふもとの日の出・日の入りで、日本時間。端末の時刻の設定や、遊ぶ人のいる場所には合わせない。04 §3.9）。
- **見本では**: 立山のピンと、「例」と書いた噂の地を1つ置いてよい。

### B2 土地の入口
- **要素**: 巻の題（例「立山の巻 ― 白い曼荼羅帳（仮）」）、山並みの切り絵の扉絵、推し妖怪の白描、**夢の旅で入る**、**現の旅で歩く**、この土地の帳の進み（白描のピースの数を絵で）、届いている便り1通、祭りの期間なら祭りの印、監修の小さな表示（了承済みのものだけ）。協定先の名前はここに出さない（お礼の札と支度のクレジットにだけ。00 §6.1-3）。
- **状態**:
  - 家にいる: 「現の旅で歩く」は淡く、「現地に来たら開きます」。
  - 現地にいる: 両方明るい。
  - お休みの日（実在の祭礼など）: 「今日は、この土地の一部がお休みです」。
- **出さないもの**: 協賛の店の名前、広告、ランキング。

### C1 夢の旅: 箱庭
- **要素**: 3Dの箱庭（光と霞）、アバターとましろ、気配（墨のにじみ）、道しるべの行灯と灯り（家＝白い紙、現地＝琥珀色）、足あと、休み処（縁台と行灯）、お休みの範囲の霧、HUD（§3.2）。
- **状態**:
  - 時間帯: 昼（初回）／夕／夜（06 §2）。夜は気配だけで、夜話は便りへ。2回目からは「いま」（立山の時刻）で始まる（04 §3.9）。
  - 夜の申し出: 「いま」で夜に入ったとき（読み込んだときも）、ページごとに一度だけ、ましろが下の案内の場所に「夜は、みんな気配だけ。」［昼の夢にする］と出す。夜話が来ていれば「夜話に、だれか来ている。」［帳の「便り」をひらく］。ボタンは1つと × だけで、急かす言葉・数・点滅は出さず、外へ出かけることはすすめない。会話・帳の間は出さない（段階4b）。
  - 気配の近く: 「耳を澄ます」が出る。
  - お休みの範囲の縁: 霧が濃くなり、それ以上進めない。
  - 未訪問の場所: 白描で淡く、歩いた所から色づく（06 §5 案B。段階2の後）。
  - 灯りがまだない（3月まで）: 行灯だけ立っていて、灯りはない。
  - 宵の集い（後の段階）: 顔のない淡い光の旅人が数人。身ぶりの輪（お辞儀・手を振る・灯りをかかげる）。

### C2 出会い・会話
- **要素**: 妖怪の板絵（夢は白描、現は色）、名前、台詞の枠、話し手の印（「台本・創作」）、選択肢、伝承の札（出典・確度つき。F-43）、「会話をやめる」。
- **決まり**: 会話の途中には何も割り込ませない（便り・祭り・協賛の通知を出さない）。

### C3 灯りを置く／読む
- **要素**: 灯りの数は「少し」「たくさん」の程度だけ。置き手紙は決まった言葉を2つ組み合わせて作る（自由入力なし）。
- **状態**: 置いた直後は自分にだけ見え、ほかの人には翌日以降に見える。

### C4 休み処の札
- **要素**: 「協力先」の印、店の名前、現地でもらえる供物、営業の時間、「買い物はしなくてよい」「寄らなくても物語は進みます」、地図で場所を見る。
- **状態**: 家（何があるかを知らせるだけ）／現地で近い（立ち寄るともらえる）／休業の日／13歳未満（出さない）。

### D1 現の旅: 地図
- **要素**: 素の地図（和風の3D地図は段階5）、気配の札、休み処の札（形を変えて「協力先」の印つき）、お休みの範囲（淡い霧の面）、状態の帯、出典表示。
- **状態**: 位置が取れない（「空が見える所で少し待ってください」）／歩いている／立ち止まった／夜（気配だけ）／逢魔が時（帰る案内）。
- **出さないもの**: ほかのプレイヤーの現在地。

### D2 お休みの範囲 ／ D3 道中 ／ D4 旅印
- D2: 出会い・カメラ・会話が止まる。世界の言葉と普通の言葉を並べる。
- D3: ましろが眠っている絵。操作はできない。降りて立ち止まると戻る。
- D4: 巻末の欄に旅印を押す動き。日付。「この印は売ったり譲ったりできません」。

### E1 帳
- **要素**: 表紙（いまは曼荼羅帳。2巻目が決まったら外側の一冊を「旅帳（仮）」にする案。00 §10 #5）、土地ごとの頁、ピースの4段階（空白 → 白描 → 彩色 → 金の縁取り）、巻末の旅印の欄。
- **出さないもの**: 協賛の名前（帳の中には載せない）。
- **状態**: まだ何もない（真っ白な頁と、ましろの一言）／家だけで進んだ土地（白描）／現地に行った土地（色）。

### E2 縁帳 ／ E3 伝承の札
- E2: 妖怪ごとの縁の糸（気配 → 顔見知り → なじみ → 語り仲間 → えにし。04 §3.3）、覚え書き、好物。
- E3: 札の題・本文・出典（文献名の1行）。確度・調べ・監修の状態はデータには持つが、画面には出さない（開発と監修の確認用に `?debug` のときだけ出す）。伝承の札と【創作】の台詞が見分けられる。

### F1 便り
- **要素**: 古笠の便り（和紙の手紙）、夜話、祭りの知らせ、噂の地の噂。
- **決まり**: 罪悪感で呼び戻す言い方をしない。プッシュ通知は使わない（02 §5.9）。未読の数を大きく出さない。
- **段階4b の試作（10/19）**: 下のタブ（§3.1）が決まるまでは、便りは帳の3つ目のタブ「便り」（夢の旅・白描の絵地図・現の旅）と、入口の「便り」（`index.html#tayori`。立山のふもとの保存）に置く。中身は、ましろの一言、逢魔が時の影（くらがり）、今夜の夜話、今日の絵解き、届いた便り（古笠が出るまでは、ましろの便りと「また聞き」。04 §3.8）。「新」は字だけで、数は出さない。現の旅の帳では、便りと今日の絵解きだけ（夜話とくらがりは家で）。

### G1 支度
- **要素**: 引き継ぎコード（匿名 ID。会員登録なし）、音、文字の大きさ、見た目（光と霞／白描）、時間帯（いま／昼／夕／夜。いま＝立山の時刻。手で選んだ時間帯は、そのページの間だけ。段階4b では、箱庭と絵地図の「時間」ボタンにある）、二つの旅のルール、土地と祈りへの配慮、現地で遊ぶときのお願い、出典とクレジット（運営 AR City Vision の名前はここに1行）、申し出の窓口へのリンク。

### H1 お礼の札
- **要素**: 祭りや巻の終わりに流れるクレジット。妖怪、監修、作り手、協定先、協賛（「協賛」の見出しの下に）。
- **決まり**: 遊びの途中には出さない。読み終わったら閉じられる。ロゴではなく文字だけ。

## 5. UI の原則（06「光と霞」に合わせる）

### 5.1 色

画面の部品の色は、06 の時間帯のパレットから取る。いまの試作（`yume/hud.ts`）の和紙と墨の色を基本にする。

| 役 | 昼（金色の午後） | 夜（深い藍） | 出どころ |
|---|---|---|---|
| 背景の空 | `#86bfd6` → `#cfe2d4` → `#f4e2b8` | `#070b1d` → `#0f1633` → `#1d2548` | 06 §2.1・§2.3 |
| 霞 | `#f6dfa6`、光の輪 `#ffe6a0` | `#161d3a` | 06 §2 |
| 和紙（札・カード） | `#faf7f0`（半透明は 0.86） | `rgba(16,20,40,0.62)` の上に文字 `#d8d4e4` | `hud.ts`、06 §2.3 出典表示 |
| 墨（文字） | `#2a2622`、薄い文字 `rgba(42,38,34,0.62)` | `#d8d4e4` | `hud.ts` |
| 罫・枠 | `rgba(42,38,34,0.22)` | `rgba(216,212,228,0.22)` | `hud.ts` から |
| 藍（主な操作） | `#3f5f8f`（合羽の藍） | `#3f5f8f` の上に明るい文字 | 06 §2.1 アバター |
| 茜（強調・少しだけ） | `#b5523b`（包みの茜） | `#c4615a`（朱い月） | 06 §2.1・§2.3 |
| 琥珀（灯り・現地） | `#ffd89a`、輪 `#ff9a48` | 同じ | 06 §2.3 道沿いの灯り |
| 白い紙の灯り（家） | `#fbf8f0`、輪 `#fff1d6` | 同じ | 06 §2.1 ましろ |

- 文字と背景の明るさの差は 4.5:1 以上（06 §2.3 の出典表示と同じ基準）。
- 朱と墨書きを組み合わせた「印」の見た目は作らない（旅印も、協力先の印も）。協力先の印は藍の小さな縁取りの文字にする。

### 5.2 文字
- 見出し・台詞・札: 明朝（いまの試作の `--title-font`: Hiragino Mincho ProN／Yu Mincho／Noto Serif JP）。
- 操作・説明・数字: ゴシック（`--ui-font`: system-ui／Hiragino Sans／Noto Sans JP）。
- 本文は 14px 以上、操作のボタンは 44px 以上の高さ（いまの試作は 36〜42px。見本から 44px にそろえる）。文字の大きさは序の口と支度で変えられる。
- 本文は横書き（読み上げと拡大で崩れやすいため）。縦書きは、短い見出し（妖怪の名前、札の題、支度の項目）と、数行の便りだけに使う。文字の大きさが「大」のときは、便りも横書きに戻す。

### 5.3 形
- 札・カードは和紙の色の角丸の板（角の丸み 10〜14px）、1px の細い罫。影はごく薄く。
- アイコンは細い墨の線だけ。社寺・鳥居・灯籠・お札・御朱印を思わせる形は使わない。
- 光の粒・霞・にじみは、背景と演出にだけ使い、文字の上には重ねない。
- **便利アプリの形にしない**（10/17 の見本の見直し）。下のタブは和紙の帯に墨の紋の絵のボタン、支度は箱庭をぼかした上に重ねる一時停止のメニュー、帳は本の見開き、便りは一通ずつ折った手紙、休み処の札は画面の半分より低い木の板にする。右に「›」の付いた設定の行や、角丸のカードの一覧を並べる形は、細かい設定（2段目）にだけ使う。
- そのときも、宗教の形に寄せない。選んだタブの印や便りの封に**朱の判子を押した形は使わない**（朱と墨書きの組み合わせになるため。§5.1）。選んだ印は琥珀の光と茜の細い線、便りの封は墨の「〆」と茜の細い帯にする。木の札は、紐の穴を付けたり吊るしたりしない（お札・絵馬に見えないように）。

### 5.4 動き
- ゆっくり（0.4〜0.8秒）、霞が晴れる・紙がめくれる動き。点滅や揺れで注意を引かない。
- 端末の「視差効果を減らす」設定のときは、動きを止めて切り替えだけにする。

### 5.5 HUD は最小限
- 箱庭と地図の上に常にあるのは、戻る・帳・ましろ・出典の4つ。耳を澄ますは必要なときだけ。
- 数字（灯りの数・人数・進み具合の%）は出さない。量は光の強さで見せる。

### 5.6 安全の表示

| 場面 | 世界の言葉 | 普通の言葉（並べて出す） |
|---|---|---|
| 歩いている | 妖怪は、立ち止まった人にしか見えない | 歩きながら画面を見ないでください |
| 乗り物 | 道中は、ましろが眠っている | 移動中は操作できません |
| 境内 | ここから先は、祈りの場所。妖怪は外で待っている | 境内ではゲームを使えません |
| 夜 | 夜は気配だけ。話は家で夜話を聞こう | 暗くなってから出歩かないでください |
| ライチョウ | 近づかないで、そっと見守って | 野生の鳥や動物を追わないでください |
| 日の入り前 | 逢魔が時。妖怪たちも帰っていく | 駅まで ○分 |

### 5.7 言葉
- 画面に「メタバース」「プラットフォーム」「サーバー」「ワールド」を出さない。「土地」「巻」「箱庭」と言う。
- 04 §7 の判断（寺の名と同じ地名を出すか）が出るまでは、岩峅寺・芦峅寺・千垣のような寺の名と同じ地名を画面に出さない。「立山の麓」「麓の箱庭」と書く（05 §4.1）。
- 協賛は「協力先」「協賛」とはっきり書く。ぼかさない。
- 見本の画面では、店名・数・灯りの横に「例」と書く。

## 6. パートナー向けの管理画面（概要）

**作る順番**: 最初は社内での JSON の編集と、点検のスクリプトで足りる。画面を作るのは2巻目の協定が見えてから。申し出の窓口だけは、一般公開の前に Web のフォームとして用意する。

| 道具 | 使う人 | 中身 | いつ |
|---|---|---|---|
| **工房**（土地の制作） | 運営、のちに協定先 | 地域パックの編集（地点・妖怪・台本・箱庭の範囲・範囲の層・祭りの暦）、監修の状態（下書き／監修中／監修済み／了承待ち。F-71）、了承の記録、開ける条件（00 §5.3）の点検表 | いまは JSON。画面は2巻目から |
| **門の審査** | 運営と監修者 | 範囲の層の自動の点検（休み処が境内・物語の地点と重なっていないか、住宅の前・私有地・学校でないか）、札ごとの監修、試遊の記録、開ける・閉じる | いまは点検のスクリプト。画面は2巻目から |
| **協力先の窓口** | お店・自治体 | 休み処の登録（場所は運営が範囲の層で確かめてから決まる）、供物の設定、営業の時間、休みの日、匿名の訪問数の集計（F-73）、「協力先の約束」（00 §6.1）への同意 | 休み処の試行のとき（最初は運営が代わりに入力） |
| **申し出の窓口** | 土地の持ち主・管理者 | 地点の除外、時間帯の制限、表記の修正。組織のメールアドレスなどで本人確認 | **一般公開の前** |
| **作り手の受付**（後で） | 招待した作り手 | 出し物の提出、自己申告の質問票、見た目の決まりの要約 | 2年目以降 |

協力先の窓口で見せる数は、地点ごとの匿名の訪問数だけ。個人の位置、時間の細かい記録、年齢は見せない。
