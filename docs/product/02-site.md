# Web サイトの構成 v0.1

> 作成日: 2026-10-17 ／ ステータス: **案。[00 プロダクトの全体像](00-vision.md) の PO 確認と一緒に見てもらう**
> 対象: ゲームの公式サイト（プレイヤー向けのページと、パートナー向けの数ページを一つのサイトにまとめる）。
> もとにした文書: [06 光と霞](../yokai-game/06-art-direction.md)、[04 §5 トーンと表現のルール](../yokai-game/04-game-design-v0.1.md)、[05 §3 二つの旅のルール](../yokai-game/05-overview-and-roadmap.md)、[08 外部への連絡の文案](../yokai-game/08-outreach-drafts.md)。
> 表記: 「（例）」は見本で、実在の店・人数・提携先ではない。ゲームの名前は仮（00 §3.2 で PO が決める。ここでは「〈ゲーム名〉」と書く）。

## 0. 方針

- **サイトは一つ**にする。プレイヤー向けがいちばん前、パートナー向けは同じサイトの中の数ページ。サイトを二つに分けると、小さな体制では説明と保守が二重になる。
- **README のテイスト（英語・絵文字・仮のロゴ・バッジ）はやめる。** 06「光と霞」に合わせる。
- **PO の以前のサイトは、まだ見ていない**（リポジトリの中になく、URL もまだいただいていない）。URL をいただければ、残す要素と変える要素を書き出す（00 §10 #8）。それまでは、以前のサイトの見た目については何も決めない。
- プレイヤー向けのページに「メタバース」「プラットフォーム」「AR City Vision」は出さない。運営の名前は、フッターと「運営について」とパートナー向けのページにだけ、隠さずに出す。
- **実績・提携・数字は、実際にあるものだけ書く。** 協力先がまだないうちは「募集中」、事例は「準備中」と書く。画面の写真には「画面は開発中のもの」、見本の店名には「例」と書く。
- 置き場所は、ゲームと同じ GitHub Pages。トップの「遊ぶ」を押すと、そのままブラウザでゲームが開く。

## 3. トップページの構成

上から順に。スマホの縦では1列、PC では左右に余白を取った1列（幅の上限 1080px 前後）。

| # | 区画 | 中身 | 背景 |
|---|---|---|---|
| 1 | **最初の画面** | ゲームの名前、見出し（§3.1）、短い一文、**「ブラウザで遊ぶ」**（いちばん大きく）、「遊び方を見る」（小さく）。ましろが横切る | 金色の霞の昼。立山連峰の切り絵の書き割りが遠くに |
| 2 | **二つの旅** | 横に流れる絵巻（横に送って見る）。1枚目「夢の旅（家で）」: 箱庭を歩き、白描の妖怪に会う。2枚目「現の旅（現地で）」: 同じ場所に立ち、色のついた本人に再会する | 背景の箱庭をそのまま見せる（板で隠さない）。夜のテーマでは絵も夜の版 |
| 3 | **妖怪と悩みごと** | キャラクターを選ぶ画面のように、推し妖怪（光蔵坊）の白描を大きく、名前は縦書き。台本の一言はゲームの会話の枠に入れる（【創作】と明記）。遊び方の4つの手順は、1行の矢印でつなぐ | 背景の箱庭 |
| 4 | **いま入れる土地** | 絵地図の一部。立山のピンと灯り。「立山の巻 ― 白い曼荼羅帳（仮）」。2巻目が決まるまでは立山だけ。**和紙の板に載せるのはこの区画だけ**（地図と表を読むため） | 夕のばら色 |
| 5 | **約束** | 3つの短い約束: 「家だけでも最後まで遊べる」「境内には入らない・描かない」「歩いた道は記録しない」。道ばたの立て札の形で並べ、それぞれ詳しい中身を開ける。お札・絵馬に見えないよう、吊るさず、紐の穴も付けない | ここから夜。背景の色に合わせて、文字の色も夜の色に切り替える |
| 6 | **お知らせ** | 最新の2〜3件（テストの募集など） | 夜の藍 |
| 7 | **最後のさそい** | もう一度「ブラウザで遊ぶ」。夜の画面で、道しるべの琥珀の灯りと朱い月 | 夜の藍 |
| 8 | **フッター** | 遊び方・ルール・配慮・伝承と監修・よくある質問・出典・運営について（AR City Vision）・協力したい方へ・申し出の窓口 | 夜の藍 |

画面の写真には、すべて「画面は開発中のもの」と添える。

### 3.1 見出しの文言の案

| 案 | 見出し | 添える一文 |
|---|---|---|
| 1（おすすめ） | **家で物語を聞き、現地で本人に会う。** | 立山の麓に住む妖怪たちの、小さな悩みをほどく旅。 |
| 2 | **妖怪の悩みを聞きに、土地へ。** | 夢の旅で出会い、現の旅で再会する。 |
| 3 | **夢で見た顔に、本当に会いに行く。** | 家から箱庭を歩き、行ける日は現地を歩く。 |

おすすめは案1。二つの旅という、このゲームにしかない形が一行で伝わり、家だけで遊ぶ人も置いていかないため。

### 3.2 ボタンと短い文の言い方
- 主なボタン: 「ブラウザで遊ぶ」（「今すぐダウンロード」とは言わない。会員登録もない）。
- 二つの旅: 「家で ― 夢の旅」「現地で ― 現の旅」。
- 協力先の募集: 「この土地を一緒にひらく方を探しています」（数や実績は書かない）。プレイヤー向けの最後のさそいには入れず、ヘッダーとフッターの「協力したい方へ」からだけ案内する。
- 寺の名と同じ地名（岩峅寺・芦峅寺・千垣）は、04 §7 の判断までは画面に出さない。「立山の麓」と書く。

## 4. トーン（06 に合わせる）

| 項目 | 決まり |
|---|---|
| 色 | 昼は金色の霞（空 `#86bfd6`→`#cfe2d4`→`#f4e2b8`、霞 `#f6dfa6`）、夕はばら色→藍、夜は深い藍（`#070b1d`→`#1d2548`）に琥珀の灯り（`#ffd89a`）と朱い月（`#c4615a`）。文字の地は和紙 `#faf7f0`、文字は墨 `#2a2622`。上から下へスクロールすると、昼 → 夕 → 夜と時間が進む。時間は3つの切り替えで、連続して変えない（06 §6.9）。切り替えるときだけ約1秒かけて重ねて変える。暗いテーマでは、最初から夜の見た目にする。夜に入ったら、テーマに関係なく文字と板の色も夜の色にする |
| 文字 | 見出しは明朝、本文はゴシック（01 §5.2 と同じ）。本文 16px 以上、行間は広め |
| 形 | 和紙の板、細い墨の線、角の丸い札。影はごく薄く |
| 絵 | 箱庭の画面、妖怪の白描、山並みの切り絵、ましろ。**社寺・鳥居・灯籠・お札・御朱印の写真や絵は使わない**。実在の家を写した写真も使わない |
| 動き | 霞がゆっくり流れる、光の粒が少し漂う。視差効果を減らす設定では止める |
| 言葉 | やさしく、短く。「メタバース」「プラットフォーム」「革新的」「次世代」のような言葉は使わない。絵文字は使わない |
| 数字 | 実際にあるものだけ。人数・協力先の数・ダウンロード数は、出るまで書かない |

## 5. README の扱い

- リポジトリの README は、**開発者向けの説明**（ゲームの起動方法、データの出典、ライセンス）に書き直す（00 §10 #6）。
- もともとの構想（AR City Vision）は、[00 プロダクトの全体像](00-vision.md) に移した。パートナー向けの言葉は「土地ひらき」のページに、いまの方針に合わせて書く。
- 直すか外すもの: 仮のロゴ、存在しないリンク（docs/setup.md・CONTRIBUTING.md・LICENSE・docs/creator-program.md）、ar-city-vision を指すバッジ、空の日本語版、基金の割合などの数字（「構想の段階の値で、まだ決まっていない」と書くか外す）。

## 6. 見本（サイトの試作）で作るもの

PO と方向を合わせるための見本。公開しない。名前・店名・数はすべて「例」と書く。

| # | ページ | 目的 | 中身 |
|---|---|---|---|
| 1 | **トップ** | 新しいテイストと、ゲームとしての見え方を確かめる | §3 の8区画。見出しは §3.1 の案を切り替えられる。ゲームの名前の候補も切り替えられる。昼 → 夕 → 夜とスクロールで時間が進む |
| 2 | **二つの旅のルール** | 約束の書き方を確かめる | 4か条（02 §4.4 を正本に、00 §4.2 と一字一句同じ）＋5つめ「お金で売らないもの」（案）。「後から削らない」 |
| 3 | **土地と祈りへの配慮** | 当事者が読んで安心できるかを確かめる | 決まりの一覧と、申し出の窓口（フォームは見た目だけ。送れない） |
| 4 | **土地ひらき（パートナー向け）** | 自治体に「ゲームの中に土地ができる」と伝わるかを確かめる | ゲームの画面から始まる説明、土地の中身、範囲の層の表、開ける条件、事例は「準備中」 |
| 5 | **休み処と協賛** | 協賛が控えめで、約束が先に立っているかを確かめる | 協力先の約束、休み処の札の見本（例）、お礼の札の見本（例）、やらないこと |

スマホの縦（幅 360〜430px、横スクロールなし）と PC の横で見られるようにする。
